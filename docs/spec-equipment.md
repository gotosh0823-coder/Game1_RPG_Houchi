# 装備システム 仕様（ドラフト）

実装前の設計文書。**[決定]** は指示済み、**[仮]** はこちらで置いた案、
**[要決定]** は判断が必要なもの。

> 入手方法の2つ目は途中で切れていましたが、通貨が「アレキサンドライト」と
> 指定されたので**ガチャ**として §6.2 に書いています。

---

## 1. 全体像

装備は **4部位 × レア度5段階 × レベル** で強さが決まる。

```
装備の性能 = 基礎値（ドロップしたステージに依存）
           × レア度倍率
           × レベル倍率
```

- **レベル**はギルで上げる。レア度ごとに上限がある
- 上限まで上げた**同じ名前の装備**を重ねると、1つ上のレア度になる（レベルは1に戻る）
- 入手は**ボスドロップ**と**ガチャ（モグボナンザ）**の2つ

**レア度は「アイテムの種類」ではなく「その1本の状態」** **[決定]**

同じ名前の装備が、レア度違いで共存する。

```
Nスファライ  ×2 ＋ ギル → Rスファライ
Rスファライ  ×3 ＋ ギル → SRスファライ
SRスファライ ×3 ＋ ギル → SSRスファライ
SSRスファライ×3 ＋ ギル → URスファライ
```

「スファライ」はモンクの格闘武器。名前がそのまま**育てる対象の識別子**になる。
最終的にはどの装備もURまで到達できる。

## 2. レア度 **[決定]**

| レア度 | レベル上限 |
| --- | --- |
| N | 10 |
| R | 20 |
| SR | 30 |
| SSR | 40 |
| UR | 50 |

**レア度倍率** **[仮]**

| レア度 | 倍率 | 上限レベルでの実効倍率 |
| --- | --- | --- |
| N | 1.00 | 1.45 |
| R | 1.60 | 2.72 |
| SR | 2.60 | 5.07 |
| SSR | 4.20 | 8.61 |
| UR | 6.80 | 16.32 |

**レベル倍率** **[仮]**：`1 + 0.05 × (Lv - 1)`

この組み合わせだと、**1つ下のレア度を上限まで育てた装備より、
1つ上のレア度のLv1のほうがわずかに強い**（N上限1.45 < R Lv1 1.60）。
合成した瞬間にレベルが1へ戻っても弱くならないので、合成をためらわなくて済む。

**[要決定]** レア度倍率の刻み（現在は約1.6倍ずつ）。
→ 大きくすると合成の価値が上がるが、UR前提のバランスになる。

## 3. 装備の区分（内部情報） **[決定]**

アイテムは内部的に2種類に分かれる。プレイヤーには明示しない。

| 区分 | 入手 | 位置づけ |
| --- | --- | --- |
| **ドロップ装備枠** | ボスドロップ | 基本の供給源。合成の素材になる |
| **ガチャ限定装備** | ガチャのみ | 同じレア度でも性能が高い、または固有の効果を持つ |

**[要決定]** ガチャ限定装備の優位性をどう出すか。
- 案A：同レア度で性能 **+30%**（単純・調整しやすい）
- 案B：固有効果を持つ（例：ダブルアタック率+5%、ヘイト倍率+0.3）
- 案C：両方

→ **[仮]** 案A（性能+30%）で置いておく。効果つきは装備の設計が一段複雑になるので、
　まず数値だけで差をつけるのが安全。

**[要決定]** ドロップ枠でURまで到達できるか。
合成が N→R→SR→SSR→UR とつながる以上、**ドロップ品だけでURは作れる**。
その前提でよければガチャの価値は「時間短縮」と「限定シリーズ」になる。

## 4. 装備グループ **[決定]**

### 4.1 防具（鎧・脚）— 3グループ

| グループ | 対象ジョブ |
| --- | --- |
| **魔道士装備** | 白魔道士 / 黒魔道士 / 赤魔道士 |
| **重量装備**（タンク系） | 戦士 / ナイト / 暗黒騎士 |
| **軽量装備** | モンク / シーフ |

> 指定に合わせると **赤魔道士は魔道士装備へ、モンクは軽量装備へ**移る。
> 中量というランクは無くなり、3グループに整理される。

**[要決定]** 未実装の上級ジョブの割り当て。
獣使い・吟遊詩人・狩人・侍・忍者・竜騎士・召喚士・青魔道士・コルセア・
からくり士・踊り子・学者・風水士・魔導剣士 の14ジョブ。
→ v2でジョブを追加するときに決めればよい（データ側は `armorGroup` を持たせるだけ）。

### 4.2 武器 — ジョブ専用 **[決定]**

武器はジョブごとの専用装備。他ジョブには装備できない。

| ジョブ | 武器 |
| --- | --- |
| 戦士 | 斧 |
| モンク | 格闘 |
| 白魔道士 | 棍 |
| 黒魔道士 | 杖 |
| 赤魔道士 | 片手剣 |
| シーフ | 短剣 |

> ジョブ専用にすると、**育てたいジョブを編成に入れてボスを回す**動機が生まれる。
> 一方で、ジョブを乗り換えるときは武器を一から集め直すことになる。

### 4.3 アクセサリ — 全ジョブ共通 **[決定]**

制限なし。どのジョブにも装備できる。

## 5. レベル強化と合成

### 5.1 レベル強化（ギル） **[決定：ギルで強化する／数値は仮]**

```
Lv n → n+1 の費用 = floor( 基礎費用 × レア度係数 × 1.28 ^ (n-1) )
```

**[仮]**

| 項目 | 値 |
| --- | --- |
| 基礎費用 | `40 × 1.40 ^ (ドロップ元ステージ - 1)` |
| レア度係数 | N 1.0 / R 1.5 / SR 2.2 / SSR 3.2 / UR 4.6 |

基礎費用をゴールドの獲得曲線（`8 × 1.40^(n-1)`）に合わせてあるので、
**どのステージで拾った装備でも「育てるのにかかる周回数」がほぼ一定**になる。

**[要決定]** 1段階ずつ上げるか、まとめて上げられるか。
→ 上限50まで1回ずつタップさせるのは苦痛なので、
　**「最大まで上げる」ボタンを用意する**のが前提。

### 5.2 合成 **[決定：流れ／数値は仮]**

**上限レベルに達した装備どうし**を合成すると、1つ上のレア度になる。
合成後のレベルは **1に戻る**。

| 合成 | 必要数 | 状態 |
| --- | --- | --- |
| N → R | N × **2** ＋ ギル | **[決定]** |
| R → SR | R × **3** ＋ ギル | **[決定]** |
| SR → SSR | SR × **3** ＋ ギル | **[仮]** |
| SSR → UR | SSR × **3** ＋ ギル | **[仮]** |

この数だと **UR 1個 = SSR 3個 = SR 9個 = R 27個 = N 54個**。

**[要決定]** SR以降の必要数（3個ずつでよいか）。
- 3個ずつ … UR1個にN54個。現実的な範囲
- 4個・5個と増やす … UR1個にN120個。URが最終目標として重くなる
- SRで打ち止め … SSRとURはガチャ限定にする。レア度に明確な壁ができる

**合成の材料は同じ名前の装備** **[決定]**

Nスファライを重ねられるのはNスファライだけ。別の格闘武器とは混ぜられない。

> これは前回の仮案（同じ部位・同じグループなら何でも可）を**否定する決定**。
> 特定の1本を集中的に狙うゲームになるので、
> **ガチャと ドロップの排出プールに何種類あるか**が難易度を直接決める（§6.3）。

**合成費用** **[仮]**：`素材1個を上限まで育てる総費用 × 0.5`

> **注意：合成のたびに育成コストが丸ごと消えます。**
> 「上限まで育ててから合成」「合成後はLv1」というルールなので、
> UR 1個を作るまでに **N54個ぶんの育成費用**を払うことになる。
> これは意図的な設計だと理解していますが、ギルの需要が非常に大きくなるので、
> ゴールドの獲得量（現在 `8 × 1.40^(n-1)`）は上方修正が必要になる見込みです。

## 6. 入手方法

### 6.1 ボスドロップ **[決定]**

**通常ボス**を倒したときにドロップ枠が判定される。

```
ドロップ率 = 20%（基本）
           + シーフのトレジャーハンター
           + アクセサリのドロップ率補正
```

**100%を超えたぶんは追加の抽選になる。**

```
確定数   = floor(ドロップ率 / 100)
追加抽選 = ドロップ率 の端数%で1個
```

例）150% → **100%で1個 ＋ 50%の抽選で1個 = 最大2個**

**[要決定]** トレジャーハンターの数値をドロップ率にも使うか。
現在は「獲得ゴールド `+10 + Lv×0.8`%」で、Lv75なら+70%。
これをそのままドロップ率に足すと、シーフ1人で 20% → 90% になる。
- 案A：同じ数値をそのまま使う（シーフの価値が非常に高くなる）
- 案B：ドロップ率へはその半分を足す（Lv75で+35%、合計55%）
→ **[仮]** 案B。案Aだとシーフが実質必須枠になる。

**[要決定]** 何が落ちるか（部位とレア度の抽選）。 **[仮]**

| 部位 | 確率 |
| --- | --- |
| 武器 / 鎧 / 脚 / アクセサリ | 各25% |

| レア度 | 確率 |
| --- | --- |
| N | 65% |
| R | 25% |
| SR | 8% |
| SSR | 2% |
| UR | 0%（ドロップしない） |

→ ステージが上がるほど高レア度の比率を上げる案もある。
　その場合は「低ステージを周回して素材を稼ぐ」戦略が消えるので、
　**据え置き**にしておくほうが放置ゲームとしては素直。

**[要決定]** どのジョブ向けの武器が落ちるか。
武器はジョブ専用なので、**編成に入っているジョブの武器から選ぶ**のが自然
（使えない武器ばかり落ちても意味がないため）。 **[仮]** その方式。

### 6.2 ガチャ「モグボナンザ」 **[決定]**

| 項目 | 値 |
| --- | --- |
| 名称 | **モグボナンザ** |
| 通貨 | **アレキサンドライト** |
| 単発 | **5個** |
| 11連 | **50個**（1回ぶん得） |
| 11連の保証 | **SR以上が1枠確定** |
| 排出内容 | **すべてガチャ限定装備**（ドロップ品は出ない） |
| デバッグ環境の初期所持 | 200個 |

**排出レア度** **[仮]**

| レア度 | 通常枠 | 確定枠（SR以上を按分） |
| --- | --- | --- |
| N | 40% | — |
| R | 40% | — |
| SR | 15% | 75% |
| SSR | 4.5% | 22.5% |
| UR | 0.5% | 2.5% |

**[要決定]** アレキサンドライトの入手方法。
ボス撃破 / 実績 / ログイン / 課金 のどれで配るか。§6.4 の試算を参照。

### 6.3 排出プールの種類数が難易度を決める

同名でしか重ねられないので、**プールに何種類あるか**で必要な回数が何倍にもなる。

**[仮] プールの絞り方**

| 部位 | 排出される種類 |
| --- | --- |
| 武器 | **編成中のジョブの武器のみ**（4ジョブなら4種） |
| 鎧・脚 | **編成中のジョブが属するグループのみ**（各3種以下） |
| アクセサリ | 1種 |

編成が 戦士 / モンク / 白 / 黒 なら、武器4 ＋ 鎧3 ＋ 脚3 ＋ アクセ1 = **11種**。

> 使えない装備が出ないようにする狙いだが、
> **編成を変えるとプールも変わる**点は注意（集めかけの装備が出なくなる）。

**[要決定]** ピックアップを設けるか。
特定の1種を高確率にする枠があると、「今日はスファライを狙う」という遊び方ができ、
種類数による希薄化も避けられる。

### 6.4 「2日で UR 1個」を成立させる数値 **[試算]**

指定の目標（UR 1個 ≒ 2日）から逆算する。

**UR 1個に必要な N の数**

```
1 UR = 3 SSR = 9 SR = 27 R = 54 N
```

**N 1個ぶんの価値に換算した、11連（50個）の期待値**

| 枠 | 内訳 | N換算 |
| --- | --- | --- |
| 通常10枠 | N 4.0 / R 4.0 / SR 1.5 / SSR 0.45 / UR 0.05 | 31.8 |
| 確定1枠 | SR 0.75 / SSR 0.225 / UR 0.025 | 9.9 |
| **合計** | | **41.7 N相当** |

**種類数で割る**

11種に散るので、狙いの1種に集まるのは 41.7 ÷ 11 ≒ **3.8 N相当 / 11連**。

```
54 N相当 ÷ 3.8 ≒ 14.2回の11連 = 約 710個
```

→ **アレキサンドライトを 1日 350個前後**配ると、目標の「2日で1個」に合う。

**[要決定]** この配布量でよいか。調整の効くところは3つ。

| 手段 | 効果 |
| --- | --- |
| アレキサンドライトの配布量 | 直接。いちばん素直 |
| 排出プールの種類数 | 種類を減らすと必要数が比例して減る |
| ピックアップの導入 | 狙った1種に集中できるので実質的に種類数を減らすのと同じ |

### 6.5 ギルの必要量が桁違いになる **[要検討]**

UR 1個を作るまでに、**すべての素材を上限レベルまで育てる**必要がある。

| 段階 | 個数 | 各々の到達レベル |
| --- | --- | --- |
| N | **54個** | Lv10 |
| R | **27個** | Lv20 |
| SR | **9個** | Lv30 |
| SSR | **3個** | Lv40 |
| UR | 1個 | Lv50 |

合計 **93個ぶんの育成費用**が、UR 1本のために消える。
しかも合成のたびにLv1へ戻るので、払った育成費用は毎回捨てることになる。

> **ギルの獲得量は上方修正が必須です。**
> 現在は `8 × 1.40^(ステージ-1)` ／1戦闘。
> 装備の育成が入ると需要が2桁は変わるので、実装時に必ず測り直す。

## 7. 所持と装備 **[要決定]**

**[仮]** 入手した装備は**共有の倉庫**に入り、各ジョブの4スロットに割り当てる。

- 防具はグループ単位なので、同じグループのジョブ間で使い回せる
- 武器はジョブ専用なので実質そのジョブ専用
- 同じ装備を2人に同時装備はできない

**[要決定]** 所持上限。
上限なしだとNが延々と溜まる。合成で消費されるとはいえ、一覧が壊れる。
- 案A：上限あり（例：200個）＋ 自動売却（指定レア度以下を自動でギルに変換）
- 案B：上限なし。並び替えと絞り込みで運用
→ **[仮]** 案A。放置ゲームなので、**寝ている間に溜まったNを自動処理**できないと
　起動のたびに整理作業が発生する。

## 7.5 装備1本のデータ **[仮]**

「同じ名前を重ねる」ため、装備は**1本ずつ独立した所持品**として持つ。

```js
{
  id: "eq_00417",        // 所持品の通し番号
  name: "スファライ",     // 育てる対象の識別子。合成はこれが一致する必要がある
  slot: "weapon",
  rarity: "SR",          // N / R / SR / SSR / UR
  level: 12,             // レア度ごとの上限まで
  source: "gacha",       // drop / gacha（内部情報・表示しない）
  baseStage: 24,         // どのステージ帯の装備か（基礎値がここで決まる）
  equippedBy: "mnk"      // 装備中のジョブ。未装備なら null
}
```

- **`name` が同じもの同士だけ合成できる**
- `rarity` と `level` はその1本の状態。同名でもバラバラ
- `baseStage` は入手時に固定。あとから上がることはない
- `equippedBy` があるので、同じ装備の二重装備を防げる

## 8. 既存の実装との差分

いまの実装（`js/data/equipment.js`）との違い。

| 項目 | 現在 | この仕様 |
| --- | --- | --- |
| 性能の決まり方 | 到達ステージのティアで自動計算 | ドロップ元ステージ × レア度 × レベル |
| 入手 | 自動で最適装備を装備している扱い | ボスドロップ / ガチャ |
| レア度 | なし | N / R / SR / SSR / UR |
| レベル | なし | ギルで強化、レア度ごとに上限 |
| 防具グループ | 重 / 中 / 軽（3ランク） | 魔道士 / 重量 / 軽量（3グループ・**割り当てが変わる**） |
| 武器 | ジョブの武器種ごと | 同じ（ジョブ専用） |
| アクセサリ | 全ジョブ共通 | 同じ |
| アイテムの持ち方 | 都度生成（所持の概念なし） | 1本ずつ独立した所持品（§7.5） |
| ガチャ | なし | モグボナンザ |

**移行で必ず起きること**

現在、プレイヤー側で**指数的に伸びる唯一の軸が装備**（耐久側1.90 / 火力側2.06）。
これをドロップ制に変えると、**装備の更新が運任せになるぶん平均的な戦力が下がる**。

→ ドロップ品の基礎値を「**ドロップ元ステージのティア**」に紐づけるのが必須。
　そうしないと、ステージ30で拾った装備がステージ1の装備と同じ強さになり、
　進行が完全に止まる。

→ そのうえで、いまの壁（ステージ31前後）は必ず動く。
　実装後に耐久側の伸びを測り直す前提で進める。

### 今回の指示で確定したこと

- ガチャ名称は **モグボナンザ**、単発5個／11連50個（SR以上1枠確定）
- 排出は**すべてガチャ限定装備**
- 合成の材料は**同じ名前の装備**（Nスファライ×2 → Rスファライ）
- 同じ名前の装備が**レア度違いで共存**する
- 最終的にどの装備も**URまで到達できる**
