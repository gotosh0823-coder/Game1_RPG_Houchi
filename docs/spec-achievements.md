# 実績ボーナス 仕様（ドラフト）

実装前の設計文書。リストは **[`data/achievements.csv`](../data/achievements.csv)**（Excelで編集可）。

実績は**装備の帯倍率の代わり**として置かれる。
50ステージごとにドロップ装備が入れ替わってリセットされるぶんを、ここで埋める。

---

## 1. 報酬の2本立て

| 報酬 | 用途 |
| --- | --- |
| **アレキサンドライト** | ガチャの通貨。実績が主な供給源になる |
| **ステータス補正** | 全ジョブに永続で乗る。装備の帯リセットを埋める |

---

## 2. ⚠ 加算%だけでは帯の切り替わりを越えられません

**先に結論から。** 実績を「全ステータス +○%」の加算だけで組むと、
現実的な設計では **全部合わせても ×2〜3 が上限**です。

CSVの提案をすべて足した場合：

| 実績 | 全ステータスへの寄与 |
| --- | --- |
| 撃破数（50段階 × 0.2%） | +10% |
| 初回入手（N〜UR） | +21% |
| 同ジョブ4人クリア（6種 × 10%） | +60%（該当ジョブのみ） |
| 各ジョブLv75（6種 × 3%） | +18% |
| アビリティ使用（20段階 × 1%） | +20% |
| オート封印（10段階 × 2%） | +20% |
| その他 | +10% 前後 |
| **合計** | **約 +120% ＝ ×2.2** |

一方、**帯が変わると失うもの**は、育て切ったドロップ装備1式ぶん：

```
レア度 N → UR    ×5.06
レベル Lv1 → 50  ×3.45
合わせて         ×17.5
```

**×2.2 では ×17.5 の穴は埋まりません。**

### 解決案：ステージ踏破実績だけを「乗算」にする **[推奨]**

ステージ踏破は **50刻み** ＝ ちょうど帯の切り替わりと一致します。
ここだけ加算%ではなく**乗算**にすると、構造がそのまま噛み合います。

| 到達 | 実績 | 効果 |
| --- | --- | --- |
| ステージ50 | 大陸踏破 I | 全ステータス **×17.5** |
| ステージ100 | 大陸踏破 II | 全ステータス **×17.5**（累積 ×306） |
| ステージ150 | 大陸踏破 III | 全ステータス **×17.5**（累積 ×5,359） |

こうすると、**帯2に入った瞬間にドロップ装備がNのLv1へ戻っても、
実績ぶんで戦力が維持される**。装備を育て直すあいだの落差がなくなります。

他の実績は加算%のままでよく、こちらは「じわじわ楽になる」役割を担います。

**[要決定]** 乗算にするのはステージ踏破だけでよいか。倍率は17.5でよいか。

---

## 3. それでも敵のカーブは下げる必要があります

実績を乗算にしても、**敵の伸び 1.45/ステージ には届きません**。

プレイヤー側で用意できる倍率をすべて足すと：

| 軸 | 倍率 |
| --- | --- |
| ジョブレベル（Lv1→75） | ×17 |
| 装備（ドロップN Lv1 → ガチャUR Lv50） | ×22.7 |
| 実績（加算ぶん） | ×2.2 |
| 実績（ステージ踏破の乗算・3段階） | ×5,359 |
| **合計** | **約 ×460万** |

対して敵は、150ステージで `1.45^149 ≒ 10^23`。まだ **17桁**足りません。

```
150ステージを踏破可能にする敵の伸び = 460万 ^ (1/149) ≒ 1.11 / ステージ
```

→ **敵の伸びを 1.45 → 1.11 前後に下げる**のが、この設計に必要な変更です。

これは `js/data/enemies.js` の3行（総HP・ATK・ゴールド）を変えるだけで済みます。
実績を実装するときに、あわせて測り直すのが効率的です。

**[要決定]** 敵のカーブを下げるタイミング（実績と同時 / 別で先に）。

### 4.2 追加のおすすめ（◎から順に）

**◎ 手動プレイに報酬を出すもの — いちばん欠けている枠**

いまのゲームは「オートにして放置する」以外に遊び方がありません。
仕様上は**手動のほうが強い**はずなのに、手で遊ぶ理由が報酬として存在しない。

| 実績 | 条件 | 狙い |
| --- | --- | --- |
| **歴戦の指揮官** | アビリティ使用 100回刻み | 押すこと自体に報酬 |
| **オート封印** | オートOFFでステージクリア 5回刻み | 手動で挑む理由を作る |

**◎ 詰まったときの救済**

| 実績 | 条件 | 狙い |
| --- | --- | --- |
| **不屈** | 全滅 10回刻み | 負けてもHPが伸びる。壁で足止めされる時間が「進んでいる」感覚になる |

放置ゲームで壁に当たったときの体験が、これがあるかどうかで大きく変わります。

**○ 既存の仕組みを回す動機**

| 実績 | 条件 | 狙い |
| --- | --- | --- |
| メタルハンター | メタルスライム撃破 10体刻み | レア枠を追う |
| ボスキラー | ボス撃破 50体刻み | 装備集めの周回 |
| 極めし者 | 各ジョブ Lv75 到達・6種 | 育成の節目 |
| 大富豪 | 累計獲得ギル 桁ごと | 放置ゲームの定番 |

**△ あってもよいもの**

| 実績 | 条件 |
| --- | --- |
| モグの常連 | ガチャ10回刻み（アレキは出さない） |
| 無傷の行軍 | 誰も戦闘不能にならずステージクリア 3回刻み |
| 蒐集家 | 所持している装備の種類数 5種刻み |

## 5. 実装に必要な計測値

いまのコードで数えられるもの／新しく記録が要るもの。

| 計測値 | 状態 |
| --- | --- |
| 敵撃破数 | `kill` イベントあり → カウンタを足すだけ |
| ボス撃破数 | `win` イベントに `isBoss` あり |
| メタルスライム撃破数 | `metal` イベントあり |
| 全滅回数 | `wipe` イベントあり |
| 最高到達ステージ | `save.maxStage` あり |
| 限界突破回数 | `jobs[].limitBreaks` あり |
| ジョブレベル | `jobs[].level` あり |
| **アビリティ使用回数** | `ability` イベントあり → カウンタを足すだけ |
| **オートOFFでのクリア** | 新規。ステージ中に一度もオートONでなかったかを記録 |
| **装備合成回数** | 装備システムと同時に追加 |
| **初回入手レア度** | 装備システムと同時に追加 |
| **累計獲得ギル** | 新規（現在は所持額のみ） |
| **同ジョブ4人でのクリア** | 新規。クリア時に編成を見る |

セーブデータには `stats: { kills: 0, bosses: 0, ... }` と
`achievements: { kills: 12, ... }`（各カテゴリの達成段階）を持たせる。
