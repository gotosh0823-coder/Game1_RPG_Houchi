# 実績ボーナス 仕様（ドラフト）

実装前の設計文書。リストは **[`data/achievements.csv`](../data/achievements.csv)**（Excelで編集可）。

実績は**装備の帯倍率の代わり**として置かれる。
50ステージごとにドロップ装備が入れ替わってリセットされるぶんを、ここで埋める。

| 報酬 | 用途 |
| --- | --- |
| **アレキサンドライト** | ガチャの通貨。実績が主な供給源になる |
| **ステータス補正** | 全ジョブに永続で乗る。装備の帯リセットを埋める |

## 2. ⚠ 加算%だけでは帯の切り替わりを越えられません

**先に結論から。** 実績を「全ステータス +○%」の加算だけで組むと、
現実的な設計では **全部合わせても ×2〜3 が上限**です。

CSVの提案をすべて足した場合：

| 実績 | 全ステータスへの寄与 |
| --- | --- |
| 撃破数（50段階 × 0.2%） | +10% |
| 初回入手（N〜UR） | +21% |
| 同ジョブ4人クリア（6種 × 10%） | +60%（該当ジョブのみ） |
| 各ジョブLv75（6種 × 3%） | +18% |
| アビリティ使用（20段階 × 1%） | +20% |
| オート封印（10段階 × 2%） | +20% |
| その他 | +10% 前後 |
| **合計** | **約 +120% ＝ ×2.2** |

一方、**帯が変わると失うもの**は、育て切ったドロップ装備1式ぶん：

```
レア度 N → UR    ×5.06
レベル Lv1 → 50  ×3.45
合わせて         ×17.5
```

**×2.2 では ×17.5 の穴は埋まりません。**

### 解決案：ステージ踏破実績だけを「乗算」にする **[決定・実装済み]**

ステージ踏破は **50刻み** ＝ ちょうど帯の切り替わりと一致します。
ここだけ加算%ではなく**乗算**にすると、構造がそのまま噛み合います。

| 到達 | 実績 | 効果 |
| --- | --- | --- |
| ステージ50 | 大陸踏破 I | 全ステータス **×17.5** |
| ステージ100 | 大陸踏破 II | 全ステータス **×17.5**（累積 ×306） |
| ステージ150 | 大陸踏破 III | 全ステータス **×17.5**（累積 ×5,359） |

こうすると、**帯2に入った瞬間にドロップ装備がNのLv1へ戻っても、
実績ぶんで戦力が維持される**。装備を育て直すあいだの落差がなくなります。

他の実績は加算%のままでよく、こちらは「じわじわ楽になる」役割を担います。

**採用済み。** 乗算はステージ踏破のみ、倍率17.5。

---

## 3. それでも敵のカーブは下げる必要があります

実績を乗算にしても、**敵の伸び 1.45/ステージ には届きません**。

プレイヤー側で用意できる倍率をすべて足すと：

| 軸 | 倍率 |
| --- | --- |
| ジョブレベル（Lv1→75） | ×17 |
| 装備（ドロップN Lv1 → ガチャUR Lv50） | ×22.7 |
| 実績（加算ぶん） | ×2.2 |
| 実績（ステージ踏破の乗算・3段階） | ×5,359 |
| **合計** | **約 ×460万** |

対して敵は、150ステージで `1.45^149 ≒ 10^23`。まだ **17桁**足りません。

```
150ステージを踏破可能にする敵の伸び = 460万 ^ (1/149) ≒ 1.11 / ステージ
```

→ **敵の伸びを 1.45 → 1.11 前後に下げる**のが、この設計に必要な変更です。

これは `js/data/enemies.js` の3行（総HP・ATK・ゴールド）を変えるだけで済みます。
実績を実装するときに、あわせて測り直すのが効率的です。

**まだ実施していません。** 理由は §7 を参照。

### 6.2 ⚠ アレキサンドライトの供給が実績だけでは足りません

実績から得られるアレキサンドライトの**総量は 12,990個**（全249段階の合計）。

| 上位の供給源 | 量 |
| --- | --- |
| 大陸踏破（10段階 × 300） | 3,000 |
| 同ジョブ4人クリア（6種 × 300） | 1,800 |
| 初めての装備（N〜UR） | 1,440 |
| 極めし者（6種 × 200） | 1,200 |
| 限界の先へ（20段階 × 50） | 1,000 |

装備仕様の試算では **UR 1個 ≒ 840個**、目標は「2日で1個」＝ **1日420個**。

```
12,990 ÷ 420 ≒ 31日ぶん
```

つまり実績は **1か月ぶんの供給**しかなく、しかも**使い切りです**。
それ以降は供給がゼロになります。

さらに序盤は偏っていて、**最初の2時間だけで970個**（2日ぶん以上）が出ます。
出だしは潤沢、あとで枯れる、という形。

→ **繰り返し手に入る供給源が別途必要です。** **[要決定]**

| 案 | 内容 |
| --- | --- |
| A | ボス撃破ごとに少量（例：1個）。周回に直結して分かりやすい |
| B | 1日1回のログインボーナス（例：50個）。日課になるが日付管理が要る |
| C | オフライン報酬に含める（12時間で50個など） |
| D | 実績を「繰り返し達成できるもの」に一部変える（例：敵1万体ごと） |

→ **A＋C の併用**を推奨。放置ゲームなので、
　「開いていても閉じていても貯まる」形が素直です。

## 7. 敵のカーブ（項目2）はまだ下げていません

指示は「1.45 → 1.11 に下げる」でしたが、**いま単独で実施すると壊れます**。

理由：装備システムがまだ**旧方式**（到達ステージ連動で2ステージごとに×2.06）のまま。
この状態で敵を1.11に落とすと、装備が 1.435/ステージ で伸びるのに対し
敵が 1.11/ステージ になり、**プレイヤーが一方的に強くなって自明なゲーム**になります。

敵のカーブを下げるのは、**装備をレア度＋レベル制に作り替えるのと同時**である必要があります。
（そちらでは装備がステージ連動で伸びなくなるため、1.11 が正しい値になる）

**次にやるなら装備システムの実装**です。そのときに敵のカーブも一緒に測り直します。
