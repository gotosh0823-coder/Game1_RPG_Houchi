# 放置RPG 初期仕様 v0（ドラフト）

このドキュメントは「最初に何を作るか」を決めるための叩き台です。
各章の末尾に **[要決定]** を置いてあるので、そこだけ潰せば実装に入れます。

---

## 1. コンセプト

> **FINAL FANTASY XI をオマージュした、ジョブ制の放置RPG。**
> 4人パーティが自動で連戦し続ける。
> プレイヤーがやることは **「編成するジョブの組み合わせ」** と
> **「固有アビリティを今使うか、温存するか」** の2つだけ。

- 通常攻撃・ターゲット選択・ウェポンスキルはすべて自動
- 戦闘中の入力は **アビリティボタン4つを押す／押さない** のみ
- ステージは **10連戦**。HP・MP・リキャストは**戦闘をまたいで持ち越す**
  → 「1戦目で女神の祝福を切るか、ボスまで残すか」が意思決定になる

**このゲームの核心**

戦闘中は「リソースをどこで吐き出すか」の判断だけ。
戦闘外は「どのジョブを並べるか」の判断だけ。
この2つ以外の操作は全部消す。

**やらないこと（v0では）**
- サポートジョブ（v1で実装）
- マルチプレイ、ランキング、課金
- 手動でのターゲット指定・隊列変更
- ストーリーテキストの作り込み

### 1.1 オマージュの扱い

ジョブ名・アビリティ名・ステータス表記（STR/DEX/VIT/AGI/INT/MND/CHR）・
「ジョブ特性」「リキャスト」「TP」「ウェポンスキル」「限界突破」などの用語は
FF11 のものを踏襲する。数値や習得タイミングは本作のバランスに合わせて調整する。

なお、これらの固有名詞は権利者のものなので、**一般公開・配布する段になったら**
名称を独自のものへ差し替えるか、非商用の個人制作として扱うかを決める必要がある。
開発中は FF11 の名称のまま進めて問題ない（後から名前だけ差し替えられるよう、
**ジョブ・アビリティの定義はすべてデータテーブルに切り出す**）。

## 2. 技術構成

| 項目 | 決定 | 理由 |
| --- | --- | --- |
| 実行環境 | ブラウザ単体（HTML + CSS + 素のJS、ビルド不要） | `index.html` を開くだけで動く。GitHub Pages にそのまま公開できる |
| 言語 | JavaScript (ES2022, ESModules) | ビルドツール無しでモジュール分割できる |
| セーブ | `localStorage` に JSON 1件 | サーバ不要 |

| データ定義 | `data/jobs.js` `data/equipment.js` に分離 | ジョブ追加（22ジョブ化）と名称差し替えをコード変更なしで行うため |
| 対応 | PC / スマホ縦持ち（レスポンシブ） | アビリティボタンは親指が届く下部に置く |

**[要決定]** TypeScript + Vite に切り替えるか。
→ 推奨は「v0は素のJSで作り切る」。動くものが出るまでを最短にしたい。

## 3. ジョブ

### 3.1 全体像

FF11 の 22ジョブを最終的に実装対象とする。v0 では **初期6ジョブ**のみ作る。

| 区分 | ジョブ | 実装 |
| --- | --- | --- |
| 初期ジョブ（6） | 戦士 / モンク / 白魔道士 / 黒魔道士 / 赤魔道士 / シーフ | **v0** |
| 上級ジョブ（16） | ナイト / 暗黒騎士 / 獣使い / 吟遊詩人 / 狩人 / 侍 / 忍者 / 竜騎士 / 召喚士 / 青魔道士 / コルセア / からくり士 / 踊り子 / 学者 / 風水士 / 魔導剣士 | v2以降、順次 |

上級ジョブは「特定条件で解放」する（FF11のジョブクエスト相当）。
条件の設計は v2 で行うが、**データ構造には最初から `unlockCondition` を持たせておく**。

### 3.2 ジョブが持つもの

ジョブごとの違いは、以下の6つで表現する。
**固有アビリティとパッシブアビリティは、それぞれ1ジョブにつき1つだけ。**

| 要素 | 内容 |
| --- | --- |
| **ステータス補正** | 7ステータス＋HP/MPの成長率を A+〜F のグレードで定義 |
| **通常行動** | 自動で繰り返す行動。物理攻撃か魔法かをジョブごとに定義 |
| **固有アビリティ** | **1つ**。リキャストを持つ能動的な技。プレイヤーが押す唯一の操作 |
| **パッシブアビリティ** | **1つ**。常時発動。ジョブレベルで効果が伸びる |
| **ジョブレベル** | ジョブごとに独立して蓄積（上限75、限界突破でLv1に戻る） |
| **装備** | 装備可能な武器種・防具ランクがジョブごとに異なる |

> 固有アビが1つになったので、**ボタンは4人ぶんの4つだけ**になる。
> スマホの画面下に一列で収まり、「どれを温存するか」の見通しも良くなる。

### 3.3 通常行動

固有アビが1つしかないため、**ジョブの個性の大半は「通常行動」が担う**。
これを物理一択にすると、黒魔道士が「120秒に1回だけ働く杖使い」になってしまう。

| ジョブ | 通常行動 | 内容 |
| --- | --- | --- |
| 戦士 | 物理 | 武器で攻撃 |
| モンク | 物理 | 素手で攻撃（手数が多い） |
| 白魔道士 | **条件分岐** | HPが70%未満の味方がいれば**ケアル**（MND×2.5回復 / MP10）、いなければ物理 |
| 黒魔道士 | **魔法** | **ファイア**（INT×1.8ダメージ / MP8）。MPが尽きたら杖で物理 |
| 赤魔道士 | 物理 | 二刀流で攻撃 |
| シーフ | 物理 | 短剣で攻撃 |

- 通常行動は**完全自動**。プレイヤーは触らない
- 白のケアル判定は「回復役が勝手に回してくれる」ための最小限のAI
  → プレイヤーが判断するのは、あくまで固有アビ（女神の祝福）を**どこで切るか**

**[要決定]** 白魔道士の自動ケアル閾値（HP70%未満）。
→ 高くすると MP切れが早まり、低くすると事故死が増える。実装後に調整する前提。

### 3.4 ステータス

FF11 に倣い、以下を持つ。

`HP / MP / STR / DEX / VIT / AGI / INT / MND / CHR`

成長率はグレードで定義する。

| グレード | 係数 |
| --- | --- |
| A+ | 1.00 |
| A | 0.90 |
| B | 0.80 |
| C | 0.70 |
| D | 0.60 |
| E | 0.50 |
| F | 0.40 |

```
限界突破回数を N とする
成長ボーナス = 1 + 0.05 × N

HP     = floor( (150 + HP係数 × 6 × (Lv-1))   × 成長ボーナス ) + 5 × N
MP     = floor( (40 + MP係数 × 3.5 × (Lv-1)) × 成長ボーナス ) + 5 × N   ※MPグレードFは常に0
その他 = floor( (5 + 係数 × 0.55 × (Lv-1))   × 成長ボーナス ) + 1 × N
```

**初期6ジョブのグレード表**

| ジョブ | HP | MP | STR | DEX | VIT | AGI | INT | MND | CHR |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 戦士 | A | F | A | B | A | C | E | D | C |
| モンク | A+ | F | A | B | A+ | B | F | C | C |
| 白魔道士 | D | A | D | D | C | D | C | A+ | B |
| 黒魔道士 | E | A+ | E | D | D | D | A+ | C | D |
| 赤魔道士 | C | B | C | B | C | B | B | B | B |
| シーフ | C | E | C | A+ | C | A | D | D | B |

> **基礎値と伸びは2回調整している。**
>
> 基礎値（HP150 / MP40）は、当初の案（30 / 0）では Lv1 が脆すぎて
> 1ステージ目のボスで詰まり、白魔道士はMP0でケアルすら撃てなかったため。
>
> レベルごとの伸び（HP6 / MP3.5 / ステータス0.55）は、当初の倍（12 / 7 / 1.1）では
> **レベルが上がるだけで味方が強くなりすぎ、敵の攻撃が最後まで脅威にならなかった**ため
> 半分に落としてある。

参考値（Lv50 / 限界突破0回 / 装備補正なし）

| ジョブ | HP | MP | 主要ステータス |
| --- | --- | --- | --- |
| 戦士 | 414 | 0 | STR 29 |
| モンク | 444 | 0 | VIT 32 |
| 白魔道士 | 326 | 194 | MND 32 |
| 黒魔道士 | 297 | 211 | INT 32 |
| 赤魔道士 | 355 | 177 | 全体的に 24〜26 |
| シーフ | 355 | 125 | DEX 32 / AGI 29 |

### 3.5 ジョブレベル

- **ジョブごとに独立**して EXP が蓄積される（FF11 と同じ）
- EXP は **編成に入れているジョブにのみ**入る
  → 「今のステージを進めたい」か「別ジョブを育てたい」かのトレードオフになる
- レベル上限は **75**。ここから先は限界突破（後述）で伸ばす

```
次レベルまでの必要EXP = floor( 40 × Lv^1.9 )
1戦闘あたりの獲得EXP  = 9 × 1.18^(ステージ-1) × (1 + 0.5 × 限界突破回数)
                        （ボス戦は5倍）
```

> EXPの伸び（1.18）を敵HPの伸び（1.45）よりかなり緩くしてあるのが要点。
> ここを揃えると、数ステージ進むだけでLv75に届いてしまい、
> 中期の成長（ジョブを育てる数時間〜数日）が丸ごと消える。

### 3.6 初期6ジョブの定義

固有アビリティのリキャストは **ジョブごとに個別設定**する。
**基本値は120秒**とし、ジョブの役割に応じて増減させる。

> **リキャストは「1ステージの所要時間」と対で読む。**
> 想定は 1ステージ（10連戦）で **90秒前後**。
> リキャストはステージ開始時にリセットされるので、120〜300秒のアビは
> **1ステージにつき1回**しか撃てない。
> つまりプレイヤーへの問いは常に「**10戦のうち、どの戦闘で切るか**」になる。

#### 戦士（WAR）
装備武器：斧 / 両手斧 / 片手剣　防具ランク：重　通常行動：物理

| 種別 | 名称 | 効果 | リキャスト |
| --- | --- | --- | --- |
| 固有アビ | **マイティストライク** | 20秒間、自身の攻撃がすべて **ダメージ2倍** | **180秒** |
| パッシブ | **ダブルアタック** | 通常攻撃時 `5 + Lv×0.2`% で2回攻撃（Lv75で20%） | — |

#### モンク（MNK）
装備武器：格闘　防具ランク：中　通常行動：物理

| 種別 | 名称 | 効果 | リキャスト |
| --- | --- | --- | --- |
| 固有アビ | **百烈拳** | 20秒間、攻撃間隔が 1/3 になる | **300秒** |
| パッシブ | **カウンター** | 被弾時 `5 + Lv×0.15`% で反撃（Lv75で16%） | — |

> 最長の300秒。マイティストライク（2倍）より手数3倍のぶん強いので、
> リキャストの差で釣り合わせる。「ボス戦まで絶対に取っておく」枠。

#### 白魔道士（WHM）
装備武器：棍　防具ランク：軽　通常行動：条件分岐（自動ケアル）

| 種別 | 名称 | 効果 | リキャスト |
| --- | --- | --- | --- |
| 固有アビ | **女神の祝福** | 味方全員の **HPとMPを全回復** | **300秒** |
| パッシブ | **女神の羽衣** | **自分が受ける全体攻撃**のダメージを `20 + Lv×0.4`% カット（Lv75で50%） | — |

> 平常時の回復は通常行動の自動ケアルが担う。
> 女神の祝福は「連戦が崩れかけた時に1回だけ切れる立て直し」。
> MPまで全回復するので、**黒魔道士のMP切れを救う**という副次的な意味も持つ。
>
> 女神の羽衣は**本人のみ**が対象。ボスの全体攻撃（§6.1）で白が落ちて
> 立て直しの手段ごと失う、という事故を防ぐための保険になっている。

#### 黒魔道士（BLM）
装備武器：杖　防具ランク：軽　通常行動：魔法（ファイア）

| 種別 | 名称 | 効果 | リキャスト |
| --- | --- | --- | --- |
| 固有アビ | **魔力の泉** | 敵全体に、通常行動（ファイア）の **20倍** のダメージ | **180秒** |
| パッシブ | **クリアマインド** | MP自然回復 `+1 + Lv×0.04`/秒（Lv75で+4/秒） | — |

```
魔力の泉のダメージ = INT × 1.8 × 20 = INT × 36（敵全体・MP0）
```

> パーティ最大の瞬間火力。敵が最大5体並ぶので、雑魚戦で場を一掃するか、
> ボス戦の単体火力として取っておくか、という判断になる。
>
> クリアマインドは「ファイアを何秒に1回撃てるか」を決める。
> MPが尽きると杖で殴るだけの存在になるので、黒の継続火力そのものを支える特性。

#### 赤魔道士（RDM）
装備武器：片手剣 / 短剣　防具ランク：中　通常行動：物理（二刀流）

| 種別 | 名称 | 効果 | リキャスト |
| --- | --- | --- | --- |
| 固有アビ | **連続魔** | 敵全体に30秒間デバフ：**防御力 -30% / 行動速度 -30%** | **120秒** |
| パッシブ | **二刀流** | 自身の攻撃間隔 `-10 - Lv×0.2`%（Lv75で-25%） | — |

> 唯一の基本値（120秒）。攻撃でも回復でもない「他の3人を強くする」枠。
> 防御-30%はパーティ全員の火力に乗るので、実質的な全体バフとして働く。

#### シーフ（THF）
装備武器：短剣　防具ランク：軽　通常行動：物理

| 種別 | 名称 | 効果 | リキャスト |
| --- | --- | --- | --- |
| 固有アビ | **絶対回避** | 15秒間、**自分＋ランダムな味方1人**の被ダメージを **0** にする | **240秒** |
| パッシブ | **トレジャーハンター** | 獲得ゴールド `+10 + Lv×0.8`%（Lv75で+70%） | — |

> 対象が「自分＋ランダム1人」なので、守りたい相手を狙って守れない。
> 保険であって確実な防御ではない、という位置づけ。
>
> トレジャーハンターは放置ゲームの経済に直結する。
> 「火力は落ちるがゴールドが増える枠」として、編成の判断材料になる。

| ジョブ | アビリティ | 種別 | リキャスト | 基本値との差 |
| --- | --- | --- | --- | --- |
| 赤魔道士 | 連続魔 | 支援 | 120秒 | **基本値** |
| 戦士 | マイティストライク | 火力 | 180秒 | やや長い |
| 黒魔道士 | 魔力の泉 | 火力 | 180秒 | やや長い |
| シーフ | 絶対回避 | 防御 | 240秒 | 長い |
| モンク | 百烈拳 | 火力 | 300秒 | 最長（切り札） |
| 白魔道士 | 女神の祝福 | 回復 | 300秒 | 最長（切り札） |

## 4. 限界突破

ジョブレベル75に到達した後の、**長期的な成長ループ**。

### 4.1 条件

以下3つをすべて満たすと、そのジョブを限界突破できる。

| 条件 | 内容 |
| --- | --- |
| ジョブレベル | **75**（上限に到達していること） |
| ゴールド | `100万 × 2.5^(N-1)`（N = 今回が何回目の突破か） |
| アイテム | **「偉大な〇〇の証」× N 個**（〇〇 = ジョブ名） |

**「偉大な〇〇の証」の入手**

| ジョブ | アイテム名 |
| --- | --- |
| 戦士 | 偉大な戦士の証 |
| モンク | 偉大なモンクの証 |
| 白魔道士 | 偉大な白魔道士の証 |
| 黒魔道士 | 偉大な黒魔道士の証 |
| 赤魔道士 | 偉大な赤魔道士の証 |
| シーフ | 偉大なシーフの証 |

- **ステージ25以上のボスを撃破**したとき、**編成に入っているジョブ**の証が
  それぞれ **8%** でドロップする
- 「育てたいジョブを編成に入れる」という EXP のルールと動機が揃う

### 4.2 効果

限界突破すると、そのジョブは **レベル1に戻る**。
ただし以下の永続ボーナスを得る（N = 累計の限界突破回数）。

| ボーナス | 内容 | 解決している問題 |
| --- | --- | --- |
| 初期ステータス | HP +5N / MP +5N / その他ステータス +1N | Lv1に戻っても素の状態ではない |
| 成長率 | 全ステータスの成長 **+5% × N**（乗算） | 突破するほど、育て切った時の到達点が上がる |
| 獲得EXP | **+50% × N** | 2周目以降の育て直しが速くなる |

**リセットされないもの**：ステージ進行、ゴールド、装備、他ジョブのレベル、解放済みジョブ

> 限界突破は**ジョブ単位のプレステージ**であり、アカウント全体はリセットしない。
> ステージを巻き戻さないので、「突破したジョブを外して別ジョブで進める」という
> 逃げ道が常にある。そのぶん気軽に踏める。
>
> 装備にレベル制限を設けないため（§7参照）、**Lv1に戻っても装備は外れない**。
> 突破直後の弱体は「素のステータスがLv1相当に戻る」ぶんだけで済む。

### 4.3 設計上の注意

**ボーナスが敵の伸びに追いつかない**

敵は指数関数（HP ×1.45/ステージ）で伸びるのに対し、
限界突破のボーナスは回数に対して線形（+5%/回）。
限界突破だけで無限に進み続けることはできない。

→ これは**意図した役割分担**。無限スケーリングは装備ティア（×1.42/ティア）が担い、
　限界突破は「装備を更新し続けるための土台を厚くする」役回りにする。

**[要決定]** 成長率ボーナス +5%/回 の数値。
→ 大きくすると「突破を回すだけのゲーム」になり、小さくすると突破する意味がなくなる。
　Lv75まで育て直す時間（数時間〜）に見合うかを、実装後に必ず再調整する。

## 5. パーティ編成

- パーティは **4枠**。解放済みジョブから自由に組む
- **同一ジョブの重複は可能**（黒×2、白×2 なども組める）
- 編成の変更は戦闘外ならいつでも可能。ペナルティなし
- 編成に入っているジョブにのみ EXP と「証」が入る

6ジョブから4枠なので、**必ず何かを捨てる**構成になる。

| 役割 | 該当ジョブ | 抜けると起きること |
| --- | --- | --- |
| 盾（ヘイト受け） | 戦士 / モンク | VITでヘイトを吸う者がいなくなり、黒と白が直接殴られて溶ける |
| 回復 | 白魔道士 | 連戦の後半で立て直せない（MPの出口も失う） |
| 単体火力 | 戦士 / モンク | ボスが時間内に落ちない |
| 全体火力 | 黒魔道士 | 雑魚戦が長引き、その間に削られる |
| 支援 | 赤魔道士 | 敵の防御が下がらず、パーティ全体の火力が落ちる |
| 保険 | シーフ | 事故が起きた時に耐える手段がない |
| 経済 | シーフ | 装備の更新が遅れる |

### 5.1 同一ジョブの重複について

重複を許すので、以下を仕様として明示しておく。

| 項目 | 挙動 |
| --- | --- |
| ジョブレベル・装備 | **ジョブに紐づく**ので、黒×2 は「まったく同じ性能の2人」になる |
| EXP・「証」 | **ジョブ単位で1回だけ**入る（2枠に入れても倍にはならない） |
| 固有アビのリキャスト | **枠ごとに独立**。黒×2 なら魔力の泉を2発撃てる |
| ボタン | 枠ごとに1つなので、同じアビが2つ並ぶ |

> 重複の旨味は「同じ切り札を2回切れる」こと。
> 一方で、**ヘイト制（§6.3）が極端な編成を自動的に罰する**。
> 黒×4 はVITが低く誰もヘイトを吸わないので、大技を撃った者から順に落ちていく。
> 火力を寄せるほど脆くなる、という形で自然に釣り合う。

**[要決定]** パーティ人数を 4人 と 6人 のどちらにするか。
→ FF11 のパーティは 6人 なので、オマージュとしては 6人 が忠実。
　ただし 6人 だと初期6ジョブを全部積めてしまい、v0 の編成の悩みが消える。
　推奨は **4人**（捨てる判断を残したい）。

## 6. 戦闘

### 6.1 進行

```
ステージ開始（HP/MP/リキャストは全快・全リセット）
      ↓
 1戦目：敵1〜5体が出現
      ↓  全滅させると即座に次の戦闘へ
 2戦目 … 9戦目          ← HP・MP・リキャストは持ち越し
      ↓
 10戦目：ボス（NM扱い・単体）
      ↓
 勝利 → 次のステージへ ／ 全滅 → 同じステージの1戦目から
```

**敵の出現数**

| 戦闘 | 敵数 |
| --- | --- |
| 1〜9戦目 | 1〜5体（ランダム。ステージが上がるほど多めに寄る） |
| 10戦目（ボス） | 1体 |

- 画面には最大5体まで並ぶ（§9）
- 敵数が多いほど1体あたりのHPを下げ、**戦闘全体の総HPは概ね一定**に保つ
  → 「全体攻撃が有利な回」と「単体火力が有利な回」が交互に来る

**敵の全体攻撃**

ボス（NM）は通常攻撃に加えて、**20秒ごとに全体攻撃**を行う。

```
全体攻撃のダメージ = 敵ATK × 1.5（味方全員）
```

- ヘイトを無視して全員に当たる ＝ **盾役では防げない唯一の攻撃**
- 白魔道士のパッシブ「女神の羽衣」はこれを軽減する（本人のみ）
- 通常戦闘の雑魚は全体攻撃を持たない

> ボス戦だけ「盾で受け切る」戦法が通用しなくなる。
> ここが、絶対回避や女神の祝福を切るタイミングの中心になる。

- **戦闘間の自動回復は HP 5% のみ**（＝連戦するほど削られていく）
- 全滅のペナルティは無し（失うのは時間だけ）。獲得済みのゴールドとEXPは保持

### 6.2 リアルタイム処理

100ms ティックで進行する。ターン制ではない。

- 各キャラと各敵は「行動ゲージ」を持ち、`行動速度 × 経過秒` で溜まる
- ゲージ満タン → 通常行動 → ゲージ0
- 味方のターゲットは自動（敵HPが最も低い個体）

```
攻撃力       = 武器D + STR × 0.5
物理ダメージ = 攻撃力 × 100 / (100 + 敵DEF) × (0.9〜1.1)
魔法ダメージ = 魔法基本値 × 100 / (100 + 敵MDEF) × 魔法攻撃力アップ
命中率       = 75 + (DEX - 敵AGI) × 0.5   （上限95% / 下限20%）
```

### 6.3 ヘイト（敵のターゲット選択）

固有アビからプロヴォーク（挑発）が外れたため、
**盾役は「ヘイト」で自然に成立させる**。FF11 のヘイトシステムのオマージュ。

```
ヘイト = ( 与えたダメージの累計
         + 回復量の累計 × 0.5
         + デバフ使用ごとに 敵HP × 0.02
         + VIT × 10 × 装備倍率 )      ← 戦闘開始時に入る初期値
       × ジョブのヘイト倍率
```

**ジョブごとのヘイト倍率**

ジョブ間のVIT差だけでは盾役が成立しなかったため、
ジョブ定義に「狙われやすさ」の倍率を持たせている（`data/jobs.js` の `hateRate`）。

| ジョブ | ヘイト倍率 |
| --- | --- |
| 戦士 | **1.5** |
| モンク / 白魔道士 / 黒魔道士 / 赤魔道士 / シーフ | 1.0 |

**ヘイトは「狙われる確率」に変換する。**

最大ヘイトの1人を必ず狙う方式だと、**盾役以外に一切攻撃が飛ばない**。
後衛のHPが減らないので、回復も緊張も意味を持たなくなる。
そこでヘイトの比率をそのまま抽選確率にする。

```
狙われる確率(%) = 自分のヘイト / 全員のヘイト合計 × 100
最低保証        = 5%（誰でも最低これだけは狙われる）
```

例）ヘイトが 戦士30 / モンク50 / 白10 / 黒10 なら、その比率で狙われる。
5%を下回った者は5%に引き上げ、その不足ぶんを上回っている者から比例して差し引く。

- 攻撃のたびに抽選する（1回の攻撃ごとに対象が変わりうる）
- 戦闘不能者は抽選から外れる
- ヘイトは戦闘ごとにリセットされる

これで以下が成立する。

| 起きること | 理由 |
| --- | --- |
| 全員がまんべんなく削られる | 確率で散るため |
| 前衛のほうがやや多く狙われる | VITぶんの初期ヘイトを持つため |
| 黒魔道士が魔力の泉を撃つと狙われやすくなる | 一撃で大量のヘイトを稼ぐため |
| 白魔道士が回復し続けると危なくなる | 回復もヘイトを生むため |

**実測の被弾率**（§14.7）

| 編成 | 結果 |
| --- | --- |
| 戦 / モ / 白 / 黒 | 戦士 **33%** / モンク 24% / 白 19% / 黒 24% |
| 戦士2枚 | 戦士2人で合計 **60%** を受ける |
| 戦士なし | 手数と火力の多いジョブに散る（モンク29% / 黒27%） |

倍率は掛け算なので、戦士を増やせばそのぶん前に立つ人数が増える。
盾役がいない編成では「特に守られていない」状態になり、後衛が普通に殴られる。

### 6.4 TP とウェポンスキル

FF11 の TP システムを踏襲する。

- 通常攻撃を当てるたびに TP +8%（最大100%）
- **TP 100% で自動的にウェポンスキルが発動**する（プレイヤー操作なし）
- ウェポンスキルは武器種ごとに固定（例：短剣＝ダンシングエッジ、格闘＝連発掌）

**[要決定]** ウェポンスキルを手動発動にするか。
→ 推奨は v0は自動。固有アビを1つに絞った意味が薄れるため。

### 6.5 アビリティ操作

画面下部に **4つ**のボタン（4人 × 固有アビ1つ）。押せる時だけ光る。

- **リキャストは戦闘をまたいで継続する**（戦闘終了でリセットされない。ステージ開始時のみリセット）
- リキャスト中もボタンは消さず、残り秒数を表示する
  → 「あと5秒待てば撃てる」という判断をさせたいため

**MPとリキャストの役割分担**

MPは画面に表示しない（§9）。表示しないものでプレイヤーの操作を止めると
「なぜ押せないのか分からない」状態になるので、**役割をきれいに分ける**。

| リソース | 消費者 | 表示 | 意味 |
| --- | --- | --- | --- |
| **MP** | **通常行動のみ**（黒のファイア MP8 / 白のケアル MP10） | 非表示 | 自動行動の持久力。プレイヤーは操作しない |
| **リキャスト** | **固有アビのみ** | ボタンに残り秒数 | 1ステージに1回だけ切れる切り札 |

- **固有アビは6ジョブすべて MP を消費しない**
  → 押せない理由が「リキャスト中」の一択になり、非表示のMPで詰まることがない
- MPはキャラ個別（FF11 準拠。戦士・モンク・シーフは実質使わない）
- MPが枯れると黒の火力と白の回復が止まる（プレイヤーには「手数が落ちた」と映る）
  → **女神の祝福がMPまで全回復する**のは、この詰みからの唯一の出口
- 黒のパッシブ「クリアマインド」は、この枯れ方の速さを直接決める

「今使うと、ボス戦で使えない」という形で効いてくる。
これが本作の唯一のジレンマなので、ここだけは絶対に単純化しない。

### 6.6 オート（放置）モード

トグルONで、AIが固有アビリティを自動使用する。

| | 手動 | オート |
| --- | --- | --- |
| アビの使い方 | プレイヤー判断 | 撃てるようになったら即撃つ |
| 結果 | 効率が良い（ボス前に温存できる） | 効率が落ちる（ボス戦でリキャスト中になりがち） |

**手動プレイの方が明確に強い**設計にする。
そのうえでオートでも「じわじわ進む」ようにして、放置ゲームとして成立させる。

**[要決定]** オートAIを賢くするか（ボス戦のみ百烈拳を使う、など）。
→ 推奨は「v0は素直な即撃ちAI」。賢いAIは後から**強化として売る**方が筋が良い。

## 7. 装備

ジョブレベルが上限75で止まるので、**無限に伸びる軸は装備が担う**。

### 7.1 スロット

v0 は 3スロット（武器 / 胴 / 装飾）。
FF11 の 16スロットは v2 以降に拡張する（データ構造は `slot` 文字列で持たせる）。

### 7.2 装備条件

**ジョブ制限のみ**。レベル制限は持たせない。

```
ブロンズソード      戦赤ナ暗
バトルアックス      戦
ヒーラーズローブ    白赤
```

- 装備を絞るのは**ジョブと値段**だけ
- レベル制限を外したことで、**限界突破でLv1に戻っても装備は外れない**
  → 突破のコストが「素のステータスが戻る」ぶんだけに収まり、突破を踏みやすくなる
- 何を装備できるかがジョブだけで決まるので、
  「このジョブを編成に入れるなら、この武器も買う」という判断が単純になる

### 7.3 入手と強化

- **店で購入**（ゴールド）。品揃えは **10ステージごとに新ティアが解放**される
- ステージが無限に続く以上、装備ティアも無限に続く ＝ 無限スケーリングの受け皿
- 装備は **+0 〜 +10** に強化できる（1段階ごとに性能 +8%）

```
装備ティア t の武器D  = floor( 6 × 1.42^(t-1) )
店売り価格            = floor( 300 × 1.45^(t-1) )
強化コスト(+n → +n+1) = floor( 価格 × 0.5 × 1.5^n )
```

> **この曲線は成立しない（実装して判明）**
>
> 敵は1ステージごとに ×1.45 で伸びるので、10ステージで約41倍になる。
> 一方この式の装備は、10ステージ進んで1ティア上がっても ×1.42 にしかならない。
> 桁が2つ足りず、数ステージで一切勝てなくなる。
>
> ティア制を維持するなら、1ティアあたりの倍率は **40倍前後**必要になる。
> v0の仮実装では、店が未実装なこともあり、装備の強さを
> ステージに対して連続的に伸ばす形にしてある（§14）。
> 店を実装する際に、この曲線をティアの価格・性能へ落とし込み直す必要がある。

**[要決定]** 装備をドロップ入手にするか、店売りのみにするか。
→ 推奨は v0は店売りのみ。ドロップはインベントリ管理UIが必要になり、
　「操作を減らす」というコンセプトと衝突する。

## 8. 経済（何が何で伸びるか）

| 通貨 | 入手 | 使い道 | 性質 |
| --- | --- | --- | --- |
| **EXP** | 敵撃破（編成中のジョブのみ） | ジョブレベル（上限75） | 有限・繰り返し |
| **ゴールド** | 敵撃破 | 装備の購入・強化、限界突破 | 無限 |
| **偉大な〇〇の証** | ステージ25以上のボス（8%） | 限界突破 | 蓄積 |

この3層構造で、放置ゲームに必要な3つの時間スケールが揃う。

- 短期（数分）：ゴールドが貯まり、装備が1段強くなる
- 中期（数時間〜数日）：ジョブが Lv75 まで育つ
- 長期（数週間）：限界突破を重ね、ジョブの到達点そのものが上がる

### 8.1 敵の数値

| 項目 | 式 | ステージ1 | ステージ10 | ステージ30 |
| --- | --- | --- | --- | --- |
| 戦闘の総HP | `110 × 1.45^(n-1)` | 110 | 約 4.1k | 約 1.8e6 |
| 通常敵HP | 総HP ÷ 敵数 | — | — | — |
| 通常敵ATK | `5 × 1.46^(n-1)` | 5 | 約 190 | 約 1.1e5 |
| 敵DEF | `2 + n × 3` | 5 | 32 | 92 |
| 敵AGI | `2 + n × 1.2` | 3 | 14 | 38 |
| ボスHP | 総HP × 15 | 1.65k | 約 62k | 約 2.7e7 |
| ゴールド | `8 × 1.40^(n-1)` | 8 | 約 232 | 約 1.3e5 |
| EXP | `9 × 1.18^(n-1)` | 9 | 約 40 | 約 1.1k |

- 敵HPの伸び（1.45）> ゴールドの伸び（1.40）＝ 進むほど自然に詰まる
- 敵ATKの伸び（1.46）> プレイヤーの耐久の伸び（1.43）＝ じわじわ危険になる
- EXPの伸び（1.18）は最も緩い ＝ レベルは先に頭打ちになる

### 8.2 レア枠：メタルスライム

通常戦闘に低確率で混ざる、特殊な敵。

| 項目 | 値 |
| --- | --- |
| 出現 | 通常戦闘（ボス戦以外）に **1%**。通常の敵に**加えて**1体出現する |
| HP | **10 固定**（ステージに依らない） |
| 魔法 | **一切無効**。ダメージ0で「無効」と表示する |
| 物理 | 当たっても **1ダメージ固定**（攻撃力・装備・バフをすべて無視） |
| 攻撃 | **してこない**（行動しない） |
| 逃走 | **10秒**で逃げる |
| 報酬 | EXP：1戦闘ぶんの **25倍** ／ ゴールド：**3倍** |

**この敵が測っているもの**

物理が1ダメージ固定なので、**攻撃力がいくら高くても意味がない**。
効くのは「15秒間に何回攻撃できるか」＝**手数**だけになる。

- モンク（攻撃速度1.3＋百烈拳で3倍）、シーフ（1.2）、赤魔道士（二刀流）が輝く
- 戦士のダブルアタックも1回ぶん多く殴れるので有効
- 黒魔道士は魔法が通らず、杖で殴るしかないうえ攻撃速度が0.8で最も遅い

つまり **火力偏重の編成ほど取り逃がす**。
「1体あたりの火力」ではなく「パーティ全体の手数」を問う枠として置いている。

> **ただし現行の数値（HP10 / 逃走10秒）では、この差はほぼ出ない。**
> 必要な手数は10回。10秒あれば最も遅い黒魔道士×4でも3.4秒で削り切れるため、
> 実測では全編成が討伐率100%になる（§14.5）。
>
> 現行の設定は「編成を問う関門」ではなく「**遭遇できたら当たりのレア枠**」。
> 手数を問う敵として機能させたい場合、効くのはHPで、
> 逃走時間 × 編成の毎秒攻撃回数を下回らない値にする必要がある
> （黒4を弾くなら HP 35 前後）。

**通常の敵とは別枠でHPを持たせている理由**

1戦闘の総HPに含めてしまうと、スライムが出た戦闘だけ他の敵が弱くなり、
「レアが出たらラッキー」ではなく「レアが出たら楽になる」になってしまう。
別枠にすることで、**倒しに行く時間そのものがコスト**になる。

**[決定]** 出現率1%・HP10・逃走10秒。

**EXP全体への寄与**

1ステージあたりの遭遇期待値は `9戦 × 1% = 0.09回`。
1回の討伐が1戦闘ぶんの25倍なので、ステージ単位では
`0.09 × 25 = 2.25戦闘ぶん`。通常の1ステージが14戦闘ぶん（9戦＋ボス5倍）なので、
**EXP全体の約 +16%** を担う計算になる。レア枠としては十分効いている量。

**DEFとAGIを線形にしている理由**

軽減率は `100 / (100 + DEF)` で効くので、DEFを指数で伸ばすと
プレイヤーの攻撃力がいくら伸びても軽減され続け、数ステージで一切勝てなくなる。
命中率も `75 + (DEX - 敵AGI) × 0.5` なので、AGIを指数で伸ばすと当たらなくなる。
**割合として効く数値は指数で伸ばしてはいけない**、というのが実装して分かったこと。

### 9.1 デバッグ用の倍速（左上）

画面左上に `×1 / ×10` を切り替えるボタンを置く。**開発用**。

- 放置ゲームは確認に実時間がかかるので、10倍速で回せるようにしてある
- セーブには残さない（リロードすると必ず等速に戻る）
- 公開時に外せるよう、ゲームループの速度倍率1箇所だけで実現している

### 9.2 表示ルール

| 要素 | 表示 |
| --- | --- |
| **HP** | **バーのみ**。数値は出さない（敵・味方とも） |
| **MP** | **非表示**（v0）。内部的には存在する（§6.5） |
| **TP** | 味方のみ、HPバーの下に細いバーで表示 |
| ジョブ名・Lv | 味方のみ表示。★の数が限界突破回数 |
| ゴールド | 画面下部に常時表示 |

- HPを数値で出さないことで、画面から**読み取る情報を「バーの残り」だけに絞る**
- TPを残すのは、「TPが溜まりきる直前にマイティストライクを入れる」といった
  タイミングの判断材料になるため

**[要決定]** TPバーを表示するか。
→ ウェポンスキルは自動発動なので、TPは厳密には見えなくても遊べる。
　推奨は表示（アビを切るタイミングの手掛かりになる）。不要なら消してMPと同じ扱いにする。

**[要決定]** キャラ・敵のグラフィックをどうするか。
→ 推奨は「v0は絵文字1文字」（⚔️👊✨🔮🗡🏹 / 🦇🐺👹）。素材集めで止まらないのが最優先。

### 9.3 敵が5体並ぶことの意味

敵の最大数を3→5に増やしたので、**全体攻撃の価値が上がる**。

- 黒魔道士の魔力の泉が、5体戦では単純に5倍近い総ダメージになる
- 一方でボス戦は単体なので、黒の価値が落ちる
- 「雑魚で使うか、ボスまで持つか」という判断が、**敵の数によって毎回変わる**

戦闘ごとに敵数がランダムなので、この判断が10連戦のあいだ繰り返される。

## 11. オフライン報酬

- ゲームを閉じた時刻を保存し、次回起動時に経過秒を計算する
- **最高到達ステージの1つ前**を、オートモードで周回したものとして報酬を計算する
  （オフライン中にステージは進まない ＝ 放置で壁は超えられない）

```
オフライン獲得 = (ステージ報酬 / ステージ攻略秒) × 経過秒 × 0.5
```

- ゴールドと EXP が入る（EXPは編成中のジョブのみ）
- **「証」はオフラインでは入手できない**（ボス撃破が必要なため）
- **効率50%**、**上限12時間**

**[要決定]** 効率と上限（50% / 12時間）。「80% / 24時間」でも成立する。

### 14.2 装備の暫定スケーリング

店が未実装なので、「最高到達ステージ相応の装備を全員が着けている」ものとして扱う。

```
装備倍率 = 1.43 ^ (最高到達ステージ - 1)
攻撃力   = (6 + STR × 0.5) × 装備倍率
魔力     = INT × 1.8 × 装備倍率
回復量   = MND × 2.5 × 装備倍率
最大HP   = 素のHP × 装備倍率
```

- 1.43 は敵HPの伸び 1.45 よりわずかに小さい
  → 進むほどゆっくり不利になり、レベルと限界突破で押し返す構造になる
- 攻撃力だけでなく **最大HPにも掛ける**のが要点。
  掛けないと、敵ATKが指数で伸びるのにHPがレベル依存（最大でも1000程度）のままなので、
  ステージ20台で全員が一撃で沈む

| 30 | 95秒 | Lv21 |

- 目標にしていた **1ステージ90秒** に序盤〜中盤が収まっている

  → 限界突破が必要になるのはこの先。壁は「死ぬ」ではなく「時間がかかる」形で現れる

### 14.5 メタルスライムの実測

出現率を100%に固定し、全員Lv40・ステージ20で300回遭遇させた結果。

**現行の数値（HP10 / 逃走10秒）**

| 編成 | 討伐率 | 平均討伐時間 |
| --- | --- | --- |
| 戦 / モ / 赤 / シ | 100% | 2.0秒 |
| モンク×2 / シーフ×2 | 100% | 2.1秒 |
| 戦 / モ / 白 / 黒 | 100% | 2.5秒 |
| 白×2 / 黒×2 | 100% | 3.1秒 |
| 黒 × 4 | 100% | 3.4秒 |

必要な手数が10回しかないため、**どの編成でも取り逃がさない**。
編成差は討伐率ではなく討伐にかかる時間（2.0秒 vs 3.4秒）にだけ出る。

**参考：HP50 / 逃走15秒だった時**

| 編成 | 討伐率 | 平均討伐時間 |
| --- | --- | --- |
| モンク×2 / シーフ×2 | 100% | 10.0秒 |

| 白×2 / 黒×2 | 68% | 14.6秒 |

### 14.6 見つかったバグ

**トーストが画面を埋め尽くす**

レベルアップやメタルスライム撃破の通知を出しっぱなしにしていたため、
倍速中やレベルが連続で上がる場面で画面全体が通知で覆われた。
同時表示を4件までに制限し、古いものから消すようにして修正。

**倒した敵に追撃が入り、撃破処理が二重に走っていた**

ウェポンスキルは通常攻撃と同じ `swing()` の中で撃たれるため、
通常攻撃で敵を倒した直後にウェポンスキルが同じ敵に当たり、
`hp <= 0` の判定が2回通っていた。

通常の敵では撃破イベントが二重に飛ぶだけだったが、
メタルスライムでは**報酬が2回入る**ため表面化した（討伐率が105%になった）。
`damageEnemy()` の先頭で、すでに倒れている相手への攻撃を弾くようにして修正。

### 14.7 レベル成長を半分に／ヘイトを確率化した結果

**1ステージの所要時間**（編成：戦士 / モンク / 白 / 黒、オートON）

| ステージ | 変更前 | 変更後 |
| --- | --- | --- |
| 10 | 82秒 | 103秒 |
| 20 | 90秒 | 140秒 |
| 30 | 95秒 | 157秒 |
| 45 | 64秒 | 134秒 |
| 55 | 50秒（Lv75到達） | 110秒（Lv75到達） |
| 70 | 80秒 | 176秒 |
| 85 | 127秒 | 268秒 |
| 90 | 147秒 | **614秒・全滅1回** |

- レベルの伸びを半分にしただけで、中盤の所要時間がおよそ **1.6倍** になった
- レベル到達ペース自体は変えていない（Lv75はどちらもステージ55前後）
- **初めて全滅が発生した**。壁が「時間がかかる」だけでなく「倒れる」形でも現れるようになった

**被弾の分布**（ゲーム内1時間、オートON）

| ジョブ | Lv25 / ステージ20〜 | Lv60 / ステージ40〜 |
| --- | --- | --- |
| 戦士 | 25.4% | 23.9% |
| モンク | 28.2% | 27.0% |
| 白魔道士 | 21.2% | 21.0% |
| 黒魔道士 | 25.2% | **28.2%** |

変更前は盾役に100%集中していたので、狙いどおり散るようにはなった。
ただし**ほぼ均等**で、高レベルでは黒魔道士が最も狙われる。

ヘイトの内訳を見ると、戦闘中に稼ぐダメージぶんより
**VITぶんの初期ヘイトのほうが大きい**。そしてジョブ間のVIT差が
（Lv50で 32 対 21 程度と）小さいため、初期ヘイトがほぼ横並びになる。
高レベルになるほど黒魔道士の火力が伸びてダメージぶんが効き、順位が逆転する。

盾役を機能させたい場合、VIT係数をいじっても差は開かない。
**ジョブごとのヘイト倍率**（例：戦士×3 / モンク×2.5 / 白×1 / 黒×1）を
持たせるのが唯一まとまった効き方をする。

| | 倍率なし | 戦士1.5倍 |
| --- | --- | --- |

**パーティ全体の被ダメージ総量が減り、白魔道士も回復先を絞れる**。

壁を戻したい場合は敵ATKの伸び（現在1.46）を上げるのが直接的。
