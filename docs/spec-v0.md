# 放置RPG 初期仕様 v0（ドラフト）

このドキュメントは「最初に何を作るか」を決めるための叩き台です。
各章の末尾に **[要決定]** を置いてあるので、そこだけ潰せば実装に入れます。

---

## 1. コンセプト

> パーティを編成せず、主人公1人がステージを自動で進み続ける。
> プレイヤーがやることは「強化の配分」と「どこで転生するか」の2つだけ。

- 1回のプレイセッションは 1〜3分（強化を数回買って閉じる）
- 閉じている間も進む（オフライン報酬）
- 数日〜数週間スケールの伸びは「転生」で担保する

**やらないこと（v0では）**
- マルチプレイ、ランキング、課金
- 手動戦闘・コマンド選択
- ストーリーテキストの作り込み

## 2. 技術構成

| 項目 | 決定 | 理由 |
| --- | --- | --- |
| 実行環境 | ブラウザ単体（HTML + CSS + 素のJS、ビルド不要） | `index.html` を開くだけで動く。GitHub Pages にそのまま公開できる |
| 言語 | JavaScript (ES2022, ESModules) | ビルドツール無しでモジュール分割できる |
| セーブ | `localStorage` に JSON 1件 | サーバ不要。容量も十分 |
| 描画 | DOM + CSS（Canvas は使わない） | 数値表示が主体のゲームなので DOM の方が実装が速い |
| 対応 | PC / スマホ縦持ち（レスポンシブ） | 放置ゲームはスマホで開かれる |

**[要決定]** TypeScript + Vite に切り替えるか。
→ 推奨は「v0は素のJSで作り切り、v1で必要なら移行」。最初の動くものが出るまでの時間を最短にしたい。

## 3. コアループ

```
ステージの敵が自動で出現
      ↓
主人公が自動で殴る（DPS × 経過秒）
      ↓
敵を倒す → ゴールド獲得
      ↓
一定数倒す → 次のステージへ
      ↓
強すぎる敵で足止め（＝壁）
      ↓
ゴールドで強化 → 壁を超える
      ↓
（十分進んだら）転生してリセット、永続ボーナス獲得
```

### 3.1 ステージ進行

- 各ステージは **敵10体** で構成。10体倒すと次ステージへ自動で進む。
- 10ステージごとに **ボス**（制限時間30秒）。倒せなければ同ステージの通常敵に戻り、再挑戦できる。
- ボスを倒すと、そのステージが「到達済み」として記録される。

### 3.2 戦闘計算

戦闘はリアルタイムシミュレーションではなく、**DPS × 経過時間** で処理する（オフライン計算と同じ式を使えるため）。

```
敵撃破時間(秒) = 敵HP / プレイヤーDPS
```

ボスのみ「30秒以内に倒せるか」の判定を行う。
→ `ボスHP / DPS <= 30` なら突破。つまり実質 **DPSチェック**。

**[要決定]** 敵の攻撃・プレイヤーのHP・被ダメージによる敗北を入れるか。
→ 推奨は「v0では入れない」。壁はボスのDPSチェックだけで作れるし、HPを入れると回復・防御・自動リトライの設計が芋づる式に増える。

## 4. 数値設計

すべて指数関数。定数は後で調整する前提の初期値。

### 4.1 敵

| 項目 | 式 | ステージ1 | ステージ10 | ステージ50 |
| --- | --- | --- | --- | --- |
| 通常敵HP | `10 × 1.55^(n-1)` | 10 | 約 1.9k | 約 5.7e9 |
| ボスHP | 通常敵HP × 12 | — | 約 23k | 約 6.9e10 |
| ゴールド | `2 × 1.45^(n-1)` | 2 | 約 150 | 約 1.4e8 |

- 敵HPの伸び（1.55）> ゴールドの伸び（1.45）にしてある。
  これにより**進むほど自然に詰まる**ので、壁を手で置かなくても壁ができる。

### 4.2 強化（ゴールド消費）

| 強化 | 効果 | 初期コスト | コスト倍率 |
| --- | --- | --- | --- |
| 攻撃力 | 基礎攻撃力 +1（レベルごと） | 10 | ×1.15 |
| 攻撃速度 | 攻撃回数 +2%（乗算） | 100 | ×1.20 |
| クリティカル | クリ率 +0.5%（上限50%）／クリ倍率2倍 | 500 | ×1.25 |
| ゴールド獲得 | 獲得ゴールド +5%（乗算） | 250 | ×1.22 |

```
DPS = 攻撃力 × 攻撃速度 × (1 + クリ率 × (クリ倍率 - 1)) × 転生倍率
```

**[要決定]** 強化の種類はこの4つでよいか（増やすなら v0 では最大6つまでにしたい）。

### 4.3 転生（プレステージ）

- 解放条件：**ステージ25のボス撃破**
- 転生すると：ステージ・ゴールド・強化レベルが全リセット、**魂（Soul）** を獲得
- 魂は失われない

```
獲得魂 = floor( (最高到達ステージ / 25) ^ 1.6 )
転生倍率 = 1 + 総魂数 × 0.10        // 魂1個につき全ダメージ +10%
```

- ステージ25で転生 → 魂1個
- ステージ50で転生 → 魂3個
- ステージ100で転生 → 魂9個

**[要決定]** 魂を「単純な倍率」ではなく「魂ショップで好きな永続強化を買う」形にするか。
→ 推奨は「v0は単純倍率、v1で魂ショップを追加」。倍率だけでも周回のモチベーションは成立する。

## 5. オフライン報酬

- ゲームを閉じた時刻を保存し、次回起動時に `経過秒` を計算する。
- **最高到達ステージの1つ前**を、その経過秒ぶん周回したものとして報酬を計算する。
  （オフライン中にステージが進むことはない ＝ 壁を放置で突破させない）

```
オフライン獲得ゴールド = (そのステージのゴールド / 撃破秒) × 経過秒 × 0.5
```

- **効率50%**、**上限12時間**
- 起動時に「留守中に◯◯ゴールド稼ぎました」のモーダルを出す

**[要決定]** 効率と上限（50% / 12時間）。広告や課金で伸ばす設計はしないので、素直に「80% / 24時間」でも成立する。

```

│  ステージ 12   敵 3/10       │  ← ヘッダ（進捗）
├─────────────────────────┤
│                                       │
│         [ 敵スプライト ]              │  ← 戦闘ビュー
│      HP ████████░░ 82%                │
│                                       │
├─────────────────────────┤
│  💰 12.4k    ⚔ DPS 340    ✨ 魂 3     │  ← ステータスバー
├─────────────────────────┤

├─────────────────────────┤
│  攻撃力     Lv.24     420 G   [買う]  │
```

- 買えない強化はグレーアウト（非表示にはしない＝目標として見せる）
- 数値は 1.2k / 3.4M / 5.6e12 形式で短縮表示

**[要決定]** 敵のグラフィックをどうするか。
→ 推奨は「v0は絵文字1文字（🦇 🐺 👹 …）」。素材集めで止まらないのが最優先。

## 7. データモデル（セーブ）

```js
{
  version: 1,
  stage: 12,            // 現在ステージ
  maxStage: 14,         // 最高到達（オフライン計算・転生報酬に使う）
  enemyIndex: 3,        // ステージ内の何体目か
  gold: 12400,
  souls: 3,
  upgrades: {           // 各強化のレベル
    attack: 24,
    speed: 8,
    crit: 3,
    gold: 5
  },
  lastSeen: 1753459200000,  // 最終保存時刻(ms)
  settings: { sound: false }
}
```

- 保存タイミング：10秒ごと ＋ `visibilitychange` ＋ `beforeunload`
- `version` を見てマイグレーションする（仕様変更で過去セーブを壊さない）
