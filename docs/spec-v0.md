# 放置RPG 初期仕様 v0（ドラフト）

このドキュメントは「最初に何を作るか」を決めるための叩き台です。
各章の末尾に **[要決定]** を置いてあるので、そこだけ潰せば実装に入れます。

---

## 1. コンセプト

> **FINAL FANTASY XI をオマージュした、ジョブ制の放置RPG。**
> 4人パーティが自動で連戦し続ける。
> プレイヤーがやることは **「編成するジョブの組み合わせ」** と
> **「固有アビリティを今使うか、温存するか」** の2つだけ。

- 通常攻撃・ターゲット選択・ウェポンスキルはすべて自動
- 戦闘中の入力は **アビリティボタン4つを押す／押さない** のみ
- ステージは **10連戦**。HP・MP・リキャストは**戦闘をまたいで持ち越す**
  → 「1戦目で女神の祝福を切るか、ボスまで残すか」が意思決定になる

**このゲームの核心**

戦闘中は「リソースをどこで吐き出すか」の判断だけ。
戦闘外は「どのジョブを並べるか」の判断だけ。
この2つ以外の操作は全部消す。

**やらないこと（v0では）**
- サポートジョブ（v1で実装）
- マルチプレイ、ランキング、課金
- 手動でのターゲット指定・隊列変更
- ストーリーテキストの作り込み

### 1.1 オマージュの扱い

ジョブ名・アビリティ名・ステータス表記（STR/DEX/VIT/AGI/INT/MND/CHR）・
「ジョブ特性」「リキャスト」「TP」「ウェポンスキル」「限界突破」などの用語は
FF11 のものを踏襲する。数値や習得タイミングは本作のバランスに合わせて調整する。

なお、これらの固有名詞は権利者のものなので、**一般公開・配布する段になったら**
名称を独自のものへ差し替えるか、非商用の個人制作として扱うかを決める必要がある。
開発中は FF11 の名称のまま進めて問題ない（後から名前だけ差し替えられるよう、
**ジョブ・アビリティの定義はすべてデータテーブルに切り出す**）。

## 2. 技術構成

| 項目 | 決定 | 理由 |
| --- | --- | --- |
| 実行環境 | ブラウザ単体（HTML + CSS + 素のJS、ビルド不要） | `index.html` を開くだけで動く。GitHub Pages にそのまま公開できる |
| 言語 | JavaScript (ES2022, ESModules) | ビルドツール無しでモジュール分割できる |
| セーブ | `localStorage` に JSON 1件 | サーバ不要 |
| 描画 | DOM + CSS（Canvas は使わない） | HPバーとボタンが主体なので DOM の方が速い |
| データ定義 | `data/jobs.js` `data/equipment.js` に分離 | ジョブ追加（22ジョブ化）と名称差し替えをコード変更なしで行うため |
| 対応 | PC / スマホ縦持ち（レスポンシブ） | アビリティボタンは親指が届く下部に置く |

**[要決定]** TypeScript + Vite に切り替えるか。
→ 推奨は「v0は素のJSで作り切る」。動くものが出るまでを最短にしたい。

## 3. ジョブ

### 3.1 全体像

FF11 の 22ジョブを最終的に実装対象とする。v0 では **初期6ジョブ**のみ作る。

| 区分 | ジョブ | 実装 |
| --- | --- | --- |
| 初期ジョブ（6） | 戦士 / モンク / 白魔道士 / 黒魔道士 / 赤魔道士 / シーフ | **v0** |
| 上級ジョブ（16） | ナイト / 暗黒騎士 / 獣使い / 吟遊詩人 / 狩人 / 侍 / 忍者 / 竜騎士 / 召喚士 / 青魔道士 / コルセア / からくり士 / 踊り子 / 学者 / 風水士 / 魔導剣士 | v2以降、順次 |

上級ジョブは「特定条件で解放」する（FF11のジョブクエスト相当）。
条件の設計は v2 で行うが、**データ構造には最初から `unlockCondition` を持たせておく**。

### 3.2 ジョブが持つもの

ジョブごとの違いは、以下の6つで表現する。
**固有アビリティとパッシブアビリティは、それぞれ1ジョブにつき1つだけ。**

| 要素 | 内容 |
| --- | --- |
| **ステータス補正** | 7ステータス＋HP/MPの成長率を A+〜F のグレードで定義 |
| **通常行動** | 自動で繰り返す行動。物理攻撃か魔法かをジョブごとに定義 |
| **固有アビリティ** | **1つ**。リキャストを持つ能動的な技。プレイヤーが押す唯一の操作 |
| **パッシブアビリティ** | **1つ**。常時発動。ジョブレベルで効果が伸びる |
| **ジョブレベル** | ジョブごとに独立して蓄積（上限75、限界突破でLv1に戻る） |
| **装備** | 装備可能な武器種・防具ランクがジョブごとに異なる |

> 固有アビが1つになったので、**ボタンは4人ぶんの4つだけ**になる。
> スマホの画面下に一列で収まり、「どれを温存するか」の見通しも良くなる。

### 3.3 通常行動

固有アビが1つしかないため、**ジョブの個性の大半は「通常行動」が担う**。
これを物理一択にすると、黒魔道士が「120秒に1回だけ働く杖使い」になってしまう。

| ジョブ | 通常行動 | 内容 |
| --- | --- | --- |
| 戦士 | 物理 | 武器で攻撃 |
| モンク | 物理 | 素手で攻撃（手数が多い） |
| 白魔道士 | **条件分岐** | HPが70%未満の味方がいれば**ケアル**（MND×2.5回復 / MP10）、いなければ物理 |
| 黒魔道士 | **魔法** | **ファイア**（INT×1.8ダメージ / MP8）。MPが尽きたら杖で物理 |
| 赤魔道士 | 物理 | 二刀流で攻撃（MPは固有アビ専用） |
| シーフ | 物理 | 短剣で攻撃 |

- 通常行動は**完全自動**。プレイヤーは触らない
- 白のケアル判定は「回復役が勝手に回してくれる」ための最小限のAI
  → プレイヤーが判断するのは、あくまで固有アビ（女神の祝福）を**どこで切るか**

**[要決定]** 白魔道士の自動ケアル閾値（HP70%未満）。
→ 高くすると MP切れが早まり、低くすると事故死が増える。実装後に調整する前提。

### 3.4 ステータス

FF11 に倣い、以下を持つ。

`HP / MP / STR / DEX / VIT / AGI / INT / MND / CHR`

成長率はグレードで定義する。

| グレード | 係数 |
| --- | --- |
| A+ | 1.00 |
| A | 0.90 |
| B | 0.80 |
| C | 0.70 |
| D | 0.60 |
| E | 0.50 |
| F | 0.40 |

```
限界突破回数を N とする
成長ボーナス = 1 + 0.05 × N

HP     = floor( (30 + HP係数 × 12 × (Lv-1)) × 成長ボーナス ) + 5 × N
MP     = floor( (MP係数 ×  7 × (Lv-1))      × 成長ボーナス ) + 5 × N
その他 = floor( (5 + 係数 × 1.1 × (Lv-1))   × 成長ボーナス ) + 1 × N
```

**初期6ジョブのグレード表**

| ジョブ | HP | MP | STR | DEX | VIT | AGI | INT | MND | CHR |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 戦士 | A | F | A | B | A | C | E | D | C |
| モンク | A+ | F | A | B | A+ | B | F | C | C |
| 白魔道士 | D | A | D | D | C | D | C | A+ | B |
| 黒魔道士 | E | A+ | E | D | D | D | A+ | C | D |
| 赤魔道士 | C | B | C | B | C | B | B | B | B |
| シーフ | C | E | C | A+ | C | A | D | D | B |

### 3.5 ジョブレベル

- **ジョブごとに独立**して EXP が蓄積される（FF11 と同じ）
- EXP は **編成に入れているジョブにのみ**入る
  → 「今のステージを進めたい」か「別ジョブを育てたい」かのトレードオフになる
- レベル上限は **75**。ここから先は限界突破（後述）で伸ばす

```
次レベルまでの必要EXP = floor( 20 × Lv^1.7 )
敵1体の獲得EXP        = floor( 4 × 1.30^(ステージ-1) ) × (1 + 0.5 × 限界突破回数)
```

### 3.6 初期6ジョブの定義

固有アビリティのリキャストは **ジョブごとに個別設定**する。
**基本値は120秒**とし、ジョブの役割に応じて増減させる。

> **リキャストは「1ステージの所要時間」と対で読む。**
> 想定は 1ステージ（10連戦）で **90秒前後**。
> リキャストはステージ開始時にリセットされるので、120〜300秒のアビは
> **1ステージにつき1回**しか撃てない。
> つまりプレイヤーへの問いは常に「**10戦のうち、どの戦闘で切るか**」になる。

#### 戦士（WAR）
装備武器：斧 / 両手斧 / 片手剣　防具ランク：重　通常行動：物理

| 種別 | 名称 | 効果 | リキャスト |
| --- | --- | --- | --- |
| 固有アビ | **マイティストライク** | 20秒間、自身の攻撃がすべて **ダメージ2倍** | **180秒** |
| パッシブ | **ダブルアタック** | 通常攻撃時 `5 + Lv×0.2`% で2回攻撃（Lv75で20%） | — |

#### モンク（MNK）
装備武器：格闘　防具ランク：中　通常行動：物理

| 種別 | 名称 | 効果 | リキャスト |
| --- | --- | --- | --- |
| 固有アビ | **百烈拳** | 20秒間、攻撃間隔が 1/3 になる | **300秒** |
| パッシブ | **カウンター** | 被弾時 `5 + Lv×0.15`% で反撃（Lv75で16%） | — |

> 最長の300秒。マイティストライク（2倍）より手数3倍のぶん強いので、
> リキャストの差で釣り合わせる。「ボス戦まで絶対に取っておく」枠。

#### 白魔道士（WHM）
装備武器：棍　防具ランク：軽　通常行動：条件分岐（自動ケアル）

| 種別 | 名称 | 効果 | リキャスト |
| --- | --- | --- | --- |
| 固有アビ | **女神の祝福** | 味方全員の **HPとMPを全回復**（MP0） | **300秒** |
| パッシブ | **クリアマインド** | MP自然回復 `+1 + Lv×0.04`/秒（Lv75で+4/秒） | — |

> 平常時の回復は通常行動の自動ケアルが担う。
> 女神の祝福は「連戦が崩れかけた時に1回だけ切れる立て直し」。
> MPまで全回復するので、**黒魔道士のMP切れを救う**という副次的な意味も持つ。

#### 黒魔道士（BLM）
装備武器：杖　防具ランク：軽　通常行動：魔法（ファイア）

| 種別 | 名称 | 効果 | リキャスト |
| --- | --- | --- | --- |
| 固有アビ | **魔力の泉** | 敵全体に、通常行動（ファイア）の **20倍** のダメージ | **180秒** |
| パッシブ | **魔法攻撃力アップ** | 魔法ダメージ `+5 + Lv×0.3`%（Lv75で+27%） | — |

```
魔力の泉のダメージ = INT × 1.8 × 20 = INT × 36（敵全体・MP0）
```

> パーティ最大の瞬間火力。ボス戦に取っておくか、雑魚戦で溶けそうな時に
> 場を一掃するか、という判断になる。

#### 赤魔道士（RDM）
装備武器：片手剣 / 短剣　防具ランク：中　通常行動：物理（二刀流）

| 種別 | 名称 | 効果 | リキャスト |
| --- | --- | --- | --- |
| 固有アビ | **連続魔** | 敵全体に30秒間デバフ：**防御力 -30% / 行動速度 -30%**（MP40） | **120秒** |
| パッシブ | **二刀流** | 自身の攻撃間隔 `-10 - Lv×0.2`%（Lv75で-25%） | — |

> 唯一の基本値（120秒）。攻撃でも回復でもない「他の3人を強くする」枠。
> 防御-30%はパーティ全員の火力に乗るので、実質的な全体バフとして働く。

#### シーフ（THF）
装備武器：短剣　防具ランク：軽　通常行動：物理

| 種別 | 名称 | 効果 | リキャスト |
| --- | --- | --- | --- |
| 固有アビ | **絶対回避** | 15秒間、**自分＋ランダムな味方1人**の被ダメージを **0** にする | **240秒** |
| パッシブ | **トレジャーハンター** | 獲得ゴールド `+10 + Lv×0.8`%（Lv75で+70%） | — |

> 対象が「自分＋ランダム1人」なので、守りたい相手を狙って守れない。
> 保険であって確実な防御ではない、という位置づけ。
>
> トレジャーハンターは放置ゲームの経済に直結する。
> 「火力は落ちるがゴールドが増える枠」として、編成の判断材料になる。

**リキャスト一覧（基本120秒からの調整）**

| ジョブ | アビリティ | 種別 | リキャスト | 基本値との差 |
| --- | --- | --- | --- | --- |
| 赤魔道士 | 連続魔 | 支援 | 120秒 | **基本値** |
| 戦士 | マイティストライク | 火力 | 180秒 | やや長い |
| 黒魔道士 | 魔力の泉 | 火力 | 180秒 | やや長い |
| シーフ | 絶対回避 | 防御 | 240秒 | 長い |
| モンク | 百烈拳 | 火力 | 300秒 | 最長（切り札） |
| 白魔道士 | 女神の祝福 | 回復 | 300秒 | 最長（切り札） |

すべて `data/jobs.js` の `recast` フィールドで1箇所から調整できるようにする。

## 4. 限界突破

ジョブレベル75に到達した後の、**長期的な成長ループ**。

### 4.1 条件

以下3つをすべて満たすと、そのジョブを限界突破できる。

| 条件 | 内容 |
| --- | --- |
| ジョブレベル | **75**（上限に到達していること） |
| ゴールド | `100万 × 2.5^(N-1)`（N = 今回が何回目の突破か） |
| アイテム | **「偉大な〇〇の証」× N 個**（〇〇 = ジョブ名） |

**「偉大な〇〇の証」の入手**

| ジョブ | アイテム名 |
| --- | --- |
| 戦士 | 偉大な戦士の証 |
| モンク | 偉大なモンクの証 |
| 白魔道士 | 偉大な白魔道士の証 |
| 黒魔道士 | 偉大な黒魔道士の証 |
| 赤魔道士 | 偉大な赤魔道士の証 |
| シーフ | 偉大なシーフの証 |

- **ステージ25以上のボスを撃破**したとき、**編成に入っているジョブ**の証が
  それぞれ **8%** でドロップする
- 「育てたいジョブを編成に入れる」という EXP のルールと動機が揃う

### 4.2 効果

限界突破すると、そのジョブは **レベル1に戻る**。
ただし以下の永続ボーナスを得る（N = 累計の限界突破回数）。

| ボーナス | 内容 | 解決している問題 |
| --- | --- | --- |
| 初期ステータス | HP +5N / MP +5N / その他ステータス +1N | Lv1に戻っても素の状態ではない |
| 成長率 | 全ステータスの成長 **+5% × N**（乗算） | 突破するほど、育て切った時の到達点が上がる |
| 獲得EXP | **+50% × N** | 2周目以降の育て直しが速くなる |

**リセットされないもの**：ステージ進行、ゴールド、装備、他ジョブのレベル、解放済みジョブ

> 限界突破は**ジョブ単位のプレステージ**であり、アカウント全体はリセットしない。
> ステージを巻き戻さないので、「突破したジョブを外して別ジョブで進める」という
> 逃げ道が常にある。そのぶん気軽に踏める。
>
> 装備にレベル制限を設けないため（§7参照）、**Lv1に戻っても装備は外れない**。
> 突破直後の弱体は「素のステータスがLv1相当に戻る」ぶんだけで済む。

### 4.3 設計上の注意

**ボーナスが敵の伸びに追いつかない**

敵は指数関数（HP ×1.45/ステージ）で伸びるのに対し、
限界突破のボーナスは回数に対して線形（+5%/回）。
限界突破だけで無限に進み続けることはできない。

→ これは**意図した役割分担**。無限スケーリングは装備ティア（×1.42/ティア）が担い、
　限界突破は「装備を更新し続けるための土台を厚くする」役回りにする。

**[要決定]** 成長率ボーナス +5%/回 の数値。
→ 大きくすると「突破を回すだけのゲーム」になり、小さくすると突破する意味がなくなる。
　Lv75まで育て直す時間（数時間〜）に見合うかを、実装後に必ず再調整する。

## 5. パーティ編成

- パーティは **4枠**。解放済みジョブから自由に組む
- **同一ジョブの重複は不可**（v0）
- 編成の変更は戦闘外ならいつでも可能。ペナルティなし
- 編成に入っているジョブにのみ EXP と「証」が入る

6ジョブから4枠なので、**必ず何かを捨てる**構成になる。

| 役割 | 該当ジョブ | 抜けると起きること |
| --- | --- | --- |
| 盾（ヘイト受け） | 戦士 / モンク | VITでヘイトを吸う者がいなくなり、黒と白が直接殴られて溶ける |
| 回復 | 白魔道士 | 連戦の後半で立て直せない（MPの出口も失う） |
| 単体火力 | 戦士 / モンク | ボスが時間内に落ちない |
| 全体火力 | 黒魔道士 | 雑魚戦が長引き、その間に削られる |
| 支援 | 赤魔道士 | 敵の防御が下がらず、パーティ全体の火力が落ちる |
| 保険 | シーフ | 事故が起きた時に耐える手段がない |
| 経済 | シーフ | 装備の更新が遅れる |

**[要決定]** パーティ人数を 4人 と 6人 のどちらにするか。
→ FF11 のパーティは 6人 なので、オマージュとしては 6人 が忠実。
　ただし 6人 だと初期6ジョブを全部積めてしまい、v0 の編成の悩みが消える。
　推奨は **4人**（捨てる判断を残したい）。

**[要決定]** 同一ジョブの重複を許すか。
→ FF11 では可能。ただし許すと「黒×4」のような極端な最適解が出やすい。推奨は不可。

## 6. 戦闘

### 6.1 進行

```
ステージ開始（HP/MP/リキャストは全快・全リセット）
      ↓
 1戦目：敵1〜3体が出現
      ↓  全滅させると即座に次の戦闘へ
 2戦目 … 9戦目          ← HP・MP・リキャストは持ち越し
      ↓
 10戦目：ボス（NM扱い・単体）
      ↓
 勝利 → 次のステージへ ／ 全滅 → 同じステージの1戦目から
```

- **戦闘間の自動回復は HP 5% のみ**（＝連戦するほど削られていく）
- 全滅のペナルティは無し（失うのは時間だけ）。獲得済みのゴールドとEXPは保持

### 6.2 リアルタイム処理

100ms ティックで進行する。ターン制ではない。

- 各キャラと各敵は「行動ゲージ」を持ち、`行動速度 × 経過秒` で溜まる
- ゲージ満タン → 通常行動 → ゲージ0
- 味方のターゲットは自動（敵HPが最も低い個体）

```
攻撃力       = 武器D + STR × 0.5
物理ダメージ = 攻撃力 × 100 / (100 + 敵DEF) × (0.9〜1.1)
魔法ダメージ = 魔法基本値 × 100 / (100 + 敵MDEF) × 魔法攻撃力アップ
命中率       = 75 + (DEX - 敵AGI) × 0.5   （上限95% / 下限20%）
```

### 6.3 ヘイト（敵のターゲット選択）

固有アビからプロヴォーク（挑発）が外れたため、
**盾役は「ヘイト」で自然に成立させる**。FF11 のヘイトシステムのオマージュ。

```
ヘイト = 与えたダメージの累計
       + 回復量の累計 × 0.5
       + デバフ使用ごとに 敵HP × 0.02
       + VIT × 10                    ← 前衛が素で稼ぐぶん
```

- 敵は **ヘイトが最も高い味方**を狙う（同値なら乱数）
- 戦闘不能者はヘイト対象から外れる

この式だけで、以下が自動的に成立する。

| 起きること | 理由 |
| --- | --- |
| 戦士・モンクが自然と殴られる | VIT が高く、常に前線で殴り続けるため |
| 黒魔道士が魔力の泉を撃つと狙われる | 一撃で大量のヘイトを稼ぐため |
| 白魔道士が回復し続けると危なくなる | 回復もヘイトを生むため |
| 盾役が落ちると崩壊が始まる | ヘイト2位以下に矛先が移るため |

> 「黒が大技を撃った直後が一番危ない」という緊張が、
> 挑発ボタンなしで生まれる。ボタンを増やさずに盾役の意味を作れる。

**[要決定]** VIT係数（×10）とデバフのヘイト量。
→ 大きすぎると前衛が常にヘイト1位で固定され、後衛の緊張が消える。
　小さすぎると黒・白が事故死し続ける。実装後に必ず調整する。

### 6.4 TP とウェポンスキル

FF11 の TP システムを踏襲する。

- 通常攻撃を当てるたびに TP +8%（最大100%）
- **TP 100% で自動的にウェポンスキルが発動**する（プレイヤー操作なし）
- ウェポンスキルは武器種ごとに固定（例：短剣＝ダンシングエッジ、格闘＝連発掌）

**[要決定]** ウェポンスキルを手動発動にするか。
→ 推奨は v0は自動。固有アビを1つに絞った意味が薄れるため。

### 6.5 アビリティ操作

画面下部に **4つ**のボタン（4人 × 固有アビ1つ）。押せる時だけ光る。

- **リキャストは戦闘をまたいで継続する**（戦闘終了でリセットされない。ステージ開始時のみリセット）
- リキャスト中もボタンは消さず、残り秒数を表示する
  → 「あと5秒待てば撃てる」という判断をさせたいため

**MPとリキャストの役割分担**

| リソース | 主な消費者 | 意味 |
| --- | --- | --- |
| **MP** | 通常行動（黒のファイア MP8 / 白のケアル MP10）と連続魔（MP40） | 連戦を通じてじわじわ枯れていく持久力 |
| **リキャスト** | 固有アビ全般 | 1ステージに1回だけ切れる切り札 |

- MPはキャラ個別（FF11 準拠。戦士・モンクは MP 0）
- 固有アビはほぼMPを使わない（女神の祝福・魔力の泉・百烈拳・絶対回避・
  マイティストライクは MP0）。**アビを縛るのはリキャストだけ**にして、
  「押すかどうか」の判断を1つの軸に絞る
- MPが枯れると黒の火力と白の回復が止まる
  → **女神の祝福がMPまで全回復する**のは、この詰みからの唯一の出口

「今使うと、ボス戦で使えない」という形で効いてくる。
これが本作の唯一のジレンマなので、ここだけは絶対に単純化しない。

### 6.6 オート（放置）モード

トグルONで、AIが固有アビリティを自動使用する。

| | 手動 | オート |
| --- | --- | --- |
| アビの使い方 | プレイヤー判断 | 撃てるようになったら即撃つ |
| 結果 | 効率が良い（ボス前に温存できる） | 効率が落ちる（ボス戦でリキャスト中になりがち） |

**手動プレイの方が明確に強い**設計にする。
そのうえでオートでも「じわじわ進む」ようにして、放置ゲームとして成立させる。

**[要決定]** オートAIを賢くするか（ボス戦のみ百烈拳を使う、など）。
→ 推奨は「v0は素直な即撃ちAI」。賢いAIは後から**強化として売る**方が筋が良い。

## 7. 装備

ジョブレベルが上限75で止まるので、**無限に伸びる軸は装備が担う**。

### 7.1 スロット

v0 は 3スロット（武器 / 胴 / 装飾）。
FF11 の 16スロットは v2 以降に拡張する（データ構造は `slot` 文字列で持たせる）。

### 7.2 装備条件

**ジョブ制限のみ**。レベル制限は持たせない。

```
ブロンズソード      戦赤ナ暗
バトルアックス      戦
ヒーラーズローブ    白赤
```

- 装備を絞るのは**ジョブと値段**だけ
- レベル制限を外したことで、**限界突破でLv1に戻っても装備は外れない**
  → 突破のコストが「素のステータスが戻る」ぶんだけに収まり、突破を踏みやすくなる
- 何を装備できるかがジョブだけで決まるので、
  「このジョブを編成に入れるなら、この武器も買う」という判断が単純になる

### 7.3 入手と強化

- **店で購入**（ゴールド）。品揃えは **10ステージごとに新ティアが解放**される
- ステージが無限に続く以上、装備ティアも無限に続く ＝ 無限スケーリングの受け皿
- 装備は **+0 〜 +10** に強化できる（1段階ごとに性能 +8%）

```
装備ティア t の武器D  = floor( 6 × 1.42^(t-1) )
店売り価格            = floor( 300 × 1.45^(t-1) )
強化コスト(+n → +n+1) = floor( 価格 × 0.5 × 1.5^n )
```

**[要決定]** 装備をドロップ入手にするか、店売りのみにするか。
→ 推奨は v0は店売りのみ。ドロップはインベントリ管理UIが必要になり、
　「操作を減らす」というコンセプトと衝突する。

## 8. 経済（何が何で伸びるか）

| 通貨 | 入手 | 使い道 | 性質 |
| --- | --- | --- | --- |
| **EXP** | 敵撃破（編成中のジョブのみ） | ジョブレベル（上限75） | 有限・繰り返し |
| **ゴールド** | 敵撃破 | 装備の購入・強化、限界突破 | 無限 |
| **偉大な〇〇の証** | ステージ25以上のボス（8%） | 限界突破 | 蓄積 |

この3層構造で、放置ゲームに必要な3つの時間スケールが揃う。

- 短期（数分）：ゴールドが貯まり、装備が1段強くなる
- 中期（数時間〜数日）：ジョブが Lv75 まで育つ
- 長期（数週間）：限界突破を重ね、ジョブの到達点そのものが上がる

### 8.1 敵の数値

| 項目 | 式 | ステージ1 | ステージ10 | ステージ30 |
| --- | --- | --- | --- | --- |
| 通常敵HP | `40 × 1.45^(n-1)` | 40 | 約 1.5k | 約 6.6e5 |
| 通常敵ATK | `5 × 1.42^(n-1)` | 5 | 約 150 | 約 5.0e4 |
| 敵DEF | `2 × 1.40^(n-1)` | 2 | 約 58 | 約 1.5e4 |
| ボスHP | 通常敵HP × 15 | 600 | 約 22k | 約 9.9e6 |
| ゴールド | `8 × 1.40^(n-1)` | 8 | 約 232 | 約 1.3e5 |
| EXP | `4 × 1.30^(n-1)` | 4 | 約 42 | 約 7.4k |

- 敵HPの伸び（1.45）> ゴールドの伸び（1.40）＝ 進むほど自然に詰まる
- EXPの伸び（1.30）は最も緩い ＝ レベルは先に頭打ちになり、装備の更新が主役になる

## 11. オフライン報酬

- ゲームを閉じた時刻を保存し、次回起動時に経過秒を計算する
- **最高到達ステージの1つ前**を、オートモードで周回したものとして報酬を計算する
  （オフライン中にステージは進まない ＝ 放置で壁は超えられない）

```
オフライン獲得 = (ステージ報酬 / ステージ攻略秒) × 経過秒 × 0.5
```

- ゴールドと EXP が入る（EXPは編成中のジョブのみ）
- **「証」はオフラインでは入手できない**（ボス撃破が必要なため）
- **効率50%**、**上限12時間**

**[要決定]** 効率と上限（50% / 12時間）。「80% / 24時間」でも成立する。
