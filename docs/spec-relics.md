# 遺物 仕様

**実装済み**（`js/data/relics.js` / `js/core/relics.js`）。

全滅したときにだけ手に入る、永続のコレクション要素。
「壁でひたすら全滅する」だけだった時間に、進行と選択を持ち込むのが狙い。

---

## 1. 基本

| 項目 | 内容 |
| --- | --- |
| 入手 | **オンライン中に全滅したときだけ**。オフライン報酬では手に入らない |
| 選択 | その帯の**未入手**からランダムに最大3種を提示し、1つ選ぶ |
| 代償 | 受け取ると**4人のジョブレベルが 15 下がる**（最低Lv1・EXPは0に戻る） |
| 見送り | 「今回は見送る」も選べる（代償も払わない）。ただし基本は受け取る |
| 重複 | **無し**。1帯につき10種、集めきるとその帯では以降なにも起きない |
| 総数 | **40種**（4帯 × 10種、ステージ1〜200） |

帯は50ステージごとで、装備の帯とは別の呼び名を持つ。

| 帯 | ステージ | 呼び名 |
| --- | --- | --- |
| 1 | 1〜50 | ロンフォール |
| 2 | 51〜100 | ジュノ |
| 3 | 101〜150 | アルテパ |
| 4 | 151〜200 | アルタイユ |

**効果は帯をまたいで同じ。** 上の帯の遺物が強いわけではない。
名前だけが変わり、別物として集める対象になる。

## 2. 10種の効果

| 名称 | 効果 | 1個あたり | 4個そろえた場合 |
| --- | --- | --- | --- |
| 巨人の心臓 | 最大HP | +50% | +200% |
| 戦神の紋章 | 攻撃力 | +50% | +200% |
| 不動の盾核 | VIT | +50% | +200% |
| 五大の結晶 | 全ステータス | +20% | +80% |
| 賢者の石版 | 獲得EXP | +100% | +400% |
| 黄金の秤 | 獲得ギル | +100% | +400% |
| 財宝の羅針盤 | 装備ドロップ率 | +30 | +120 |
| 時忘れの砂時計 | アビリティのリキャスト | -40% | 上限80% |
| 疾風の足環 | 行動速度 | +30% | +120% |
| 護りの古印 | 被ダメージ | -20% | 上限80% |

## 3. ⚠ 効果量は「代償に見合うか」で決まる

**この数値だけは感覚で決められない。** レベル15は思っているより重い。

Lv60の戦士のSTRは `5 + 1.8 × 0.55 × 59 = 63`、Lv45だと `50`。
つまり**受け取った瞬間に約2割弱くなる**。効果が小さいと、
「遺物を集めるほど弱くなる」という逆転が起きる。

**実測**（詰まったステージで受け取る前提・4回ずつ）

| 効果量 | 到達ステージ | 判定 |
| --- | --- | --- |
| 受け取らない | 84〜87 | 基準 |
| ×1（当初案） | 44〜48 | **罠**。取るほど弱くなる |
| ×3 | 86〜91 | ようやく損をしない |
| **×5（採用）** | **93〜95** | 取る価値がある |
| ×8 | 97〜98 | 遺物が主軸になりすぎる |

当初案の値（最大HP +10% など）は、**取るほど到達ステージが半分になる**設定だった。
×5 にして初めて「代償を払ってでも取る」が成立する。

**べき乗カーブに移行したあとの再測定**（8回）

| 条件 | 到達ステージ |
| --- | --- |
| 全滅したら受け取る | **93〜105** |
| 受け取らない | 65〜69 |

さらに「Lv40になるまで見送る」方針で測ると、Lv40に届く前に止まって
**8回とも45〜49で終わった**。
遺物は温存するものではなく、**ステージ40前後の関門を越えるための道具**になっている。

## 4. 全滅が起きないと content が開かない

遺物は全滅でしか手に入らないので、**全滅の頻度そのものが前提条件**になる。

作った直後に測ったところ、**1周（ステージ93まで）で全滅は0〜1回**しかなかった。
敵の総HPと攻撃力を同じ ×1.09 で伸ばしていたため、進行が止まるときの
止まり方が「時間がかかるだけで誰も死なない」になっていたため。

そこで**敵の攻撃力だけ ×1.10 に上げた**（総HPは ×1.09 のまま）。

| 敵ATKの伸び | 1周の全滅回数 | 到達ステージ |
| --- | --- | --- |
| 1.09 | 0〜1回 | 93 |
| 1.095 | 2〜4回 | 89〜90 |
| **1.10（採用）** | **15〜18回** | **93〜94** |
| 1.105 | 26〜33回 | 不安定（48〜83） |
| 1.11 | 9〜19回 | 42〜43（壁が崩れる） |

1周で15〜18回全滅し、遺物は **12〜14個**（40種中）集まる。

## 5. 遺物は「周回の目的」＝ほぼ必須

**代償を払ってでも集めるのが正解。**

| 条件 | 到達ステージ |
| --- | --- |
| 全滅したら受け取る | **93〜105** |
| 受け取らない | 65〜69 |
| Lv40になるまで見送る | **45〜49**（Lv40に届く前に止まる） |

いちばん早いのは、**壁で全滅を繰り返してその帯の10種を先に取り切り、
そのあとレベルを上げ直す**やり方。
レベルは戻せるが、遺物は全滅しないと手に入らないため。

## 6. 「見送る」を残してある理由

レベルが低いうちに代償を払うと、
**全滅 → レベル低下 → さらに全滅** の悪循環に入って抜けられなくなる。

実際、simで「提示されたら必ず取る」方針にすると、
6回中6回が到達ステージ44〜48で止まった（取らない場合は84〜87）。

そのため選択肢には**「今回は見送る」を残してある**。
指示は「3種類から選択」だったが、
「いまは払えない」を選べないと詰むケースがあるため。
とはいえ**基本は受け取る**もので、温存する要素ではない。

## 7. レベル代償の効き方（正直な注記）

**この代償は序盤〜中盤に重く、終盤ほど軽い。**

**追記：EXPを指数からべき乗に変えたことで、この問題はほぼ解消した。**
**さらにジョブレベルをキャラクターごとに持つようにしたので、
代償は「4人ぶんのレベル」になった**（以前は同じジョブを2枠に入れても1回ぶんだった）。

以前は EXP収入が指数（`1.18^n`）で伸びるのに必要EXPは多項式だったため、
ステージ60では**1戦闘で6レベル**上がり、-15の代償が事実上ゼロだった。

いまは収入も総HPと同じべき乗（指数3.0）なので、レベルは最後まで
「じわじわ上がるもの」であり続ける（Lv75に届くのはステージ78〜92）。
実測でも、遺物を受け取るかどうかで到達ステージが 93〜105 と 65〜69 に分かれる
＝代償も効果もどちらも効いている状態になっている。

なお終盤には「**Lv75に戻るまで限界突破できない**」という代償も乗る。
