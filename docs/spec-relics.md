# 遺物 仕様

**実装済み**（`js/data/relics.js` / `js/core/relics.js`）。

全滅したときにだけ手に入る、永続のコレクション要素。
「壁でひたすら全滅する」だけだった時間に、進行と選択を持ち込むのが狙い。

---

## 1. 基本

| 項目 | 内容 |
| --- | --- |
| 入手 | **オンライン中に全滅したときだけ**。オフライン報酬では手に入らない |
| 選択 | その帯の**未入手**からランダムに最大3種を提示し、1つ選ぶ |
| 代償 | 受け取ると**編成中のジョブレベルが 15 下がる**（最低Lv1・EXPは0に戻る） |
| 見送り | 「見送る」を選べば何も起きない（代償も払わない） |
| 重複 | **無し**。1帯につき10種、集めきるとその帯では以降なにも起きない |
| 総数 | **40種**（4帯 × 10種、ステージ1〜200） |

帯は50ステージごとで、装備の帯とは別の呼び名を持つ。

| 帯 | ステージ | 呼び名 |
| --- | --- | --- |
| 1 | 1〜50 | ロンフォール |
| 2 | 51〜100 | ジュノ |
| 3 | 101〜150 | アルテパ |
| 4 | 151〜200 | アルタイユ |

**効果は帯をまたいで同じ。** 上の帯の遺物が強いわけではない。
名前だけが変わり、別物として集める対象になる。

## 3. ⚠ 効果量は「代償に見合うか」で決まる

**この数値だけは感覚で決められない。** レベル15は思っているより重い。

Lv60の戦士のSTRは `5 + 1.8 × 0.55 × 59 = 63`、Lv45だと `50`。
つまり**受け取った瞬間に約2割弱くなる**。効果が小さいと、
「遺物を集めるほど弱くなる」という逆転が起きる。

**実測**（詰まったステージで受け取る前提・4回ずつ）

| 効果量 | 到達ステージ | 判定 |
| --- | --- | --- |
| 受け取らない | 84〜87 | 基準 |
| ×1（当初案） | 44〜48 | **罠**。取るほど弱くなる |
| ×3 | 86〜91 | ようやく損をしない |
| **×5（採用）** | **93〜95** | 取る価値がある |
| ×8 | 97〜98 | 遺物が主軸になりすぎる |

当初案の値（最大HP +10% など）は、**取るほど到達ステージが半分になる**設定だった。
×5 にして初めて「代償を払ってでも取る」が成立する。

## 4. 全滅が起きないと content が開かない

遺物は全滅でしか手に入らないので、**全滅の頻度そのものが前提条件**になる。

作った直後に測ったところ、**1周（ステージ93まで）で全滅は0〜1回**しかなかった。
敵の総HPと攻撃力を同じ ×1.09 で伸ばしていたため、進行が止まるときの
止まり方が「時間がかかるだけで誰も死なない」になっていたため。

そこで**敵の攻撃力だけ ×1.10 に上げた**（総HPは ×1.09 のまま）。

| 敵ATKの伸び | 1周の全滅回数 | 到達ステージ |
| --- | --- | --- |
| 1.09 | 0〜1回 | 93 |
| 1.095 | 2〜4回 | 89〜90 |
| **1.10（採用）** | **15〜18回** | **93〜94** |
| 1.105 | 26〜33回 | 不安定（48〜83） |
| 1.11 | 9〜19回 | 42〜43（壁が崩れる） |

1周で15〜18回全滅し、遺物は **12〜14個**（40種中）集まる。

## 5. 「見送る」が要る理由

レベルが低いうちに代償を払うと、
**全滅 → レベル低下 → さらに全滅** の悪循環に入って抜けられなくなる。

実際、simで「提示されたら必ず取る」方針にすると、
6回中6回が到達ステージ44〜48で止まった（取らない場合は84〜87）。

そのため選択肢には**「見送る（代償を払わない）」を必ず出す**。
指示は「3種類から選択」だったが、断れないと成立しないため追加している。

## 6. レベル代償の効き方（正直な注記）

**この代償は序盤〜中盤に重く、終盤ほど軽い。**

必要EXPはレベルの多項式（`40 × Lv^1.9`・上限75）なのに対して、
EXP収入は指数（`9 × 1.16^(n-1)`）で伸びる。
進むほど「15レベルを取り戻す時間」は短くなっていく。

作業中に見つかったが、**EXPの伸びが 1.18 のままだと
ステージ60で1戦闘＝6レベルになり、代償が事実上ゼロだった**。
1.16 に下げて回復に約27戦かかるようにしたが、それでも終盤では
2ステージ程度で戻る。

終盤に残る実質的な代償は「**Lv75に戻るまで限界突破できない**」こと。
限界突破が終盤の主軸なので、そこは最後まで効く。
