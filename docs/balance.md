# バランス定数の一覧

実装に入っている倍率・固定値をすべて並べたもの。**コードが正**で、この文書は写し。
値を変えたら、この表も一緒に更新すること。

`⚠` は、変えると壁の位置が大きく動くもの。

---

## 1. 味方が強くなる要素

プレイヤーの戦力に効く数値。これが「強化」の全体像。

### 1.1 ジョブレベル（EXPで伸びる・上限75）

`js/core/stats.js`

| 項目 | 値 | 備考 |
| --- | --- | --- |
| レベル上限 | **75** | `jobs.js` の `LEVEL_CAP` |
| HP 基礎値 | **150** | Lv1の値 |
| MP 基礎値 | **40** | MPグレードFの戦士・モンクは常に0 |
| ステータス基礎値 | **5** | STR/DEX/VIT/AGI/INT/MND/CHR 共通 |
| HP 1レベルあたり | **6** × グレード係数 | ⚠ 当初12から半減 |
| MP 1レベルあたり | **3.5** × グレード係数 | ⚠ 当初7から半減 |
| ステータス 1レベルあたり | **0.55** × グレード係数 | ⚠ 当初1.1から半減 |
| 必要EXP | `floor(40 × Lv^1.9)` | Lv1→2で40、Lv74→75で約17万 |

```
HP     = floor( (150 + HP係数 × 6 × (Lv-1))   × 限界突破ボーナス ) + 5 × 突破回数
MP     = floor( (40 + MP係数 × 3.5 × (Lv-1))  × 限界突破ボーナス ) + 5 × 突破回数
その他 = floor( (5 + 係数 × 0.55 × (Lv-1))    × 限界突破ボーナス ) + 1 × 突破回数
```

**グレード係数**（`jobs.js` の `GRADE`）

| A+ | A | B | C | D | E | F |
| --- | --- | --- | --- | --- | --- | --- |
| 1.00 | 0.90 | 0.80 | 0.70 | 0.60 | 0.50 | 0.40 |

## 3. 戦闘の固定値

`js/core/battle.js`

| 項目 | 値 |
| --- | --- |
| ティック | **0.1秒** |
| MP自然回復（全員共通） | **1.0 / 秒** |
| 白の自動ケアル閾値 | HP **70%** 未満 |
| ケアルのMP消費 | **10** |
| ファイアのMP消費 | **8** |
| TP蓄積（命中1回） | **8%** |
| ウェポンスキル倍率 | **×3.0** |
| 戦闘間の自動回復 | 最大HPの **5%** |
| ヘイトの最低保証 | **5%** |

**計算式**

```
攻撃力       = 武器D + STR × 0.5 × 装備倍率
魔力         = INT × 1.8 × 装備倍率
回復量       = MND × 2.5 × 装備倍率

物理ダメージ = 攻撃力 × 100 / (100 + 敵DEF) × (0.9〜1.1)
魔法ダメージ = 魔力   × 100 / (100 + 敵MDEF)
被ダメージ   = 敵ATK × 100 / (100 + VIT × 2) × (0.9〜1.1)
命中率       = 75 + (DEX - 相手AGI) × 0.5   （20〜95%）
```

**ヘイト**

```
ヘイト = ( 与ダメージ累計
         + 回復量累計 × 0.5
         + デバフ1回ごとに 敵HP × 0.02
         + 女神の祝福1回ごとに 自分の最大HP × 0.5
         + VIT × 10 × 装備倍率 )      ← 戦闘開始時の初期値
       × ジョブのヘイト倍率
```

比率をそのまま狙われる確率にし、5%を下回る者は5%へ引き上げ、
不足ぶんを上回っている者から比例して差し引く。

## 4. 敵の数値（強化の対抗軸）

`js/data/enemies.js`。n = ステージ番号。

| 項目 | 式 | ステージ1 | 10 | 30 |
| --- | --- | --- | --- | --- |
| 1戦闘の総HP | `110 × 1.45^(n-1)` | 110 | 4.1k | 1.8M |
| 敵ATK | `5 × 1.46^(n-1)` | 5 | 190 | 110k |
| 敵DEF | `2 + n × 3` | 5 | 32 | 92 |
| 敵AGI | `2 + n × 1.2` | 3 | 14 | 38 |

- 通常敵1体のHP = 総HP ÷ 敵数（何体出ても総量は一定）
- DEFとAGIは割合として効くので、**指数で伸ばしてはいけない**（線形にしてある）

**ボス（10戦目）**

| 項目 | 値 |
| --- | --- |
| HP | 総HP **×15** |
| ATK | 通常敵の **×1.2** |
| 全体攻撃の間隔 | **20秒ごと** |
| 全体攻撃の倍率 | ATK **×1.5** |
| ゴールド・EXP | **×5** |

**敵の出現数**

```
偏り = min(2, (ステージ-1) / 15)
敵数 = round( 乱数 × (3 + 偏り) + 1 + 偏り × 0.5 )   → 1〜5体に丸める
```

**メタルスライム**

| 項目 | 値 |
| --- | --- |
| 出現率 | **1%**（ボス戦を除く） |
| HP | **10** 固定 |
| 物理ダメージ | **1** 固定 |
| 魔法 | **無効** |
| 逃走 | **10秒** |
| EXP | 1戦闘ぶんの **×25** |
| ゴールド | **×3** |

## 7. 強化要素を足すときの注意

装備倍率（§1.2）が壁の位置をほぼ単独で決めており、
**30ステージぶん複利で効くため異常に敏感**。

`1.425`（全滅しない）と `1.415`（ステージ20で停止）の差はわずか **0.7%**。
ステージ30時点の戦力差にすると約23%で、それが生死を分けている。

恒久的な強化を1つ足すだけで壁が10ステージ以上動くので、
**強化要素を追加したら必ず §1.2 を測り直すこと**。

壁の位置を1つの指数の小数第3位で決めている構造自体が脆いので、
強化要素が増えてきた段階で、壁を別の仕組み（ステージごとの明示的な難易度係数など）
に移すことも検討したほうがよい。
