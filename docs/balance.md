# バランス定数の一覧

実装に入っている倍率・固定値をすべて並べたもの。**コードが正**で、この文書は写し。
値を変えたら、この表も一緒に更新すること。

`⚠` は、変えると壁の位置が大きく動くもの。

---

## 1. 味方が強くなる要素

プレイヤーの戦力に効く数値。これが「強化」の全体像。

### 1.1 ジョブレベル（EXPで伸びる・上限75）

`js/core/stats.js`

| 項目 | 値 | 備考 |
| --- | --- | --- |
| レベル上限 | **75** | `jobs.js` の `LEVEL_CAP` |
| HP 基礎値 | **150** | Lv1の値 |
| MP 基礎値 | **40** | MPグレードFの戦士・モンクは常に0 |
| ステータス基礎値 | **5** | STR/DEX/VIT/AGI/INT/MND/CHR 共通 |
| HP 1レベルあたり | **6** × グレード係数 | |
| MP 1レベルあたり | **3.5** × グレード係数 | |
| ステータス 1レベルあたり | **0.55** × グレード係数 | |
| 必要EXP | `floor(40 × Lv^1.9)` | Lv1→2で40、Lv74→75で約17万 |

```
HP     = floor( (150 + HP係数 × 6 × (Lv-1))   × 限界突破ボーナス ) + 5 × 突破回数
MP     = floor( (40 + MP係数 × 3.5 × (Lv-1))  × 限界突破ボーナス ) + 5 × 突破回数
その他 = floor( (5 + 係数 × 0.55 × (Lv-1))    × 限界突破ボーナス ) + 1 × 突破回数
```

**グレード係数**（`jobs.js` の `GRADE`）

| A+ | A | B | C | D | E | F |
| --- | --- | --- | --- | --- | --- | --- |
| **2.00** | 1.80 | 1.60 | 1.40 | 1.20 | 1.00 | 0.80 |

> 係数を2倍にしたので、1レベルあたりの伸び（6 / 3.5 / 0.55）と掛け合わせると
> 半減する前の曲線に戻る。Lv50の素のステータスは HP 679（戦士）／
> 主要ステータス 53〜59 程度。

### 1.2 装備（4部位・所持品制）

`js/core/inventory.js` / `js/data/equipment-list.js`。
到達ステージから自動でティアが決まる暫定仕様は**廃止**した。
いまは1本ずつ拾って持ち、ギルでレベルを上げ、同じ名称を重ねて合成する。

| 項目 | 値 | 備考 |
| --- | --- | --- |
| 部位 | 武器 / 鎧 / 脚 / アクセサリ | |
| 所持上限 | **200本** | 超えたぶんは自動でギルに変わる |
| 帯（ドロップ装備の切り替わり） | **50ステージごと** | 全40帯（ステージ1〜2000） |
| 帯倍率 | **1.0**（帯が変わっても基礎値は同じ） | 差は実績ボーナスとガチャ装備で埋める |
| 装備の総数 | **533種**（ドロップ520 / ガチャ13） | `data/equipment.csv` が原本 |

**レア度**（`RARITY`）

| レア度 | 倍率 | レベル上限 | 強化費用の係数 | 合成に必要な数 |
| --- | --- | --- | --- | --- |
| N | 1.0000 | 10 | 1.0 | 2 |
| R | 1.5000 | 20 | 1.5 | 3 |
| SR | 2.2500 | 30 | 2.2 | 3 |
| SSR | 3.3750 | 40 | 3.2 | 3 |
| UR | 5.0625 | 50 | 4.6 | — |

```
実効ステータス = 基礎値 × レア度倍率 × (1 + 0.05 × (レベル - 1))
```

N Lv1 が 1.00 倍、UR Lv50 が 5.0625 × 3.45 = **約17.5倍**。
これがゲーム全体を通しての、装備による伸びの上限になる。
UR1本を作るのに N が 54本 必要（2×3×3×3）。

**強化・合成の費用**（ギル・線形）

```
基準額     = max(40, その帯の開始ステージのゴールド × 5)
レベル+1   = 基準額 × レア度係数 × 現在レベル
合成       = 基準額 × レア度係数 × (上限Lv × (上限Lv+1) / 2) × 0.5
```

帯の開始ステージを基準にしているので、帯の前半は重く、後半は軽い（意図どおり）。

**基礎値（すべての帯で共通）**

| 部位 | 種別 | 補正 |
| --- | --- | --- |
| 武器 | 斧（戦士） | atk 9 / STR 4 |
| 武器 | 格闘（モンク） | atk 6 / STR 3 / VIT 2 |
| 武器 | 棍（白） | atk 4 / MND 6 |
| 武器 | 杖（黒） | atk 3 / INT 6 |
| 武器 | 片手剣（赤） | atk 7 / STR 2 / INT 2 / MND 2 |

| 鎧 | 重量（戦士） | HP 70 / VIT 5 |
| 鎧 | 魔道士（白・黒・赤） | HP 35 / MP 15 / INT 2 / MND 2 |

### 1.3 限界突破

`js/core/save.js`。突破回数を N とする。

| 項目 | 値 |
| --- | --- |
| 条件：ジョブレベル | **75** |
| 条件：ゴールド | `到達ステージの1戦闘ゴールド × 10 × 15 × 2^(N-1)` |
| 条件：アイテム | 「偉大な〇〇の証」 **N個** |
| 効果：レベル | **1に戻る** |
| 効果：成長ボーナス | **1 + 0.05 × N**（全ステータスに乗算） |
| 効果：初期ステータス | HP **+5N** / MP **+5N** / その他 **+1N** |
| 効果：獲得EXP | **1 + 0.5 × N** 倍 |

> 固定額（100万ギル）だったが、ギルの伸びを敵に合わせて ×1.09/ステージ に
> 落とした時点で「一生払えない額」になったため、到達ステージの稼ぎを基準にした
> 相対額に変えた。1回目は約10ステージぶんの稼ぎで貯まる。
> 実際の関門は最後まで「証」（1ボス8%）のほうで、n個集めるのに約12.5nステージ。
> UIは編成画面にある。

## 3. 戦闘の固定値

`js/core/battle.js`

| 項目 | 値 |
| --- | --- |
| ティック | **0.1秒** |
| MP自然回復（全員共通） | **1.0 / 秒** |
| 白の自動ケアル閾値 | HP **70%** 未満 |
| ケアルのMP消費 | **10** |
| ファイアのMP消費 | **8** |
| TP蓄積（命中1回） | **8%** |
| ウェポンスキル倍率 | **×3.0** |
| 戦闘間の自動回復 | 最大HPの **5%** |
| ヘイトの最低保証 | **5%** |

**計算式**

```
ステータス   = レベルぶん + 装備4部位の合計

攻撃力       = 武器のatk + STR × 0.5
魔力         = INT × 1.8
回復量       = MND × 2.5

物理ダメージ = 攻撃力 × 100 / (100 + 敵DEF) × (0.9〜1.1)
魔法ダメージ = 魔力   × 100 / (100 + 敵MDEF)
被ダメージ   = 敵ATK × 敵ATK / (敵ATK + VIT × 2) × (0.9〜1.1)
命中率       = 75 + (DEX - 相手AGI) × 0.5   （20〜95%）
```

**ヘイト**

```
ヘイト = ( 与ダメージ累計
         + 回復量累計 × 0.5
         + デバフ1回ごとに 敵HP × 0.02
         + 女神の祝福1回ごとに 自分の最大HP × 0.5
         + VIT × 10 )                 ← 戦闘開始時の初期値
       × ジョブのヘイト倍率
```

比率をそのまま狙われる確率にし、5%を下回る者は5%へ引き上げ、
不足ぶんを上回っている者から比例して差し引く。

## 4. 敵の数値（強化の対抗軸）

`js/data/enemies.js`。n = ステージ番号。

| 項目 | 式 | ステージ1 | 10 | 30 | 50 | 90 |
| --- | --- | --- | --- | --- | --- | --- |
| 1戦闘の総HP | ⚠ `110 × 1.09^(n-1)` | 110 | 239 | 1.3k | 7.4k | 233k |
| 敵ATK | ⚠ `5 × 1.09^(n-1)` | 5 | 11 | 61 | 337 | 10.6k |
| 敵DEF | `2 + n × 3` | 5 | 32 | 92 | 152 | 272 |
| 敵AGI | `2 + n × 1.2` | 3 | 14 | 38 | 62 | 110 |

- 通常敵1体のHP = 総HP ÷ 敵数（何体出ても総量は一定）
- DEFとAGIは割合として効くので、**指数で伸ばしてはいけない**（線形にしてある）

**伸び率 1.09 の根拠**

装備を所持品制に作り替えるまでは ×1.45 だった。これは「到達ステージから装備が
自動で決まる」前提の値で、装備が自力で集めるものになった時点で成立しなくなった。

いまプレイヤー側で指数的に伸びる軸は2本しかない。

| 軸 | 伸び | 効き方 |
| --- | --- | --- |
| 装備（レア度×レベル） | 最大 **×17.5** | ゲーム全体で一度きり。帯をまたいでも積み上がらない |
| 実績「大陸踏破」 | **×17.5 / 50ステージ** | 唯一、繰り返し掛かる |

持続する伸びは後者だけで、1ステージあたりに直すと `17.5^(1/50) ≒ 1.059`。
**敵の伸びが 1.059 を超えたぶんは、いつか必ず壁になる。**

**実測**（ヘッドレスsim・最善手で回した場合の壁）

| 伸び | 壁 | 到達までの時間 |
| --- | --- | --- |
| 1.07 | 壁なし（250到達） | 17.7h |
| 1.08 | 140 | 11.7h |
| **1.09**（現在） | **91〜93** | 6.9〜7.3h |
| 1.10 | 43 | 3.6h |
| 1.12 | 33 | 1.6h |
| 1.14 | 28 | 1.8h |
| 1.45（旧） | 10 | 0.8h |

1.09 を採った理由は、帯2（ステージ51〜）と「大陸踏破」の乗算を**必ず1回は通り**、
そのうえで壁が残るため。帯の切り替わりと実績の乗算が両方とも体験できる。

**ボス（10戦目）**

| 項目 | 値 |
| --- | --- |
| HP | 総HP **×15** |
| ATK | 通常敵の **×1.2** |
| 全体攻撃の間隔 | **20秒ごと** |
| 全体攻撃の倍率 | ATK **×1.5** |
| ゴールド・EXP | **×5** |

**敵の出現数**

```
偏り = min(2, (ステージ-1) / 15)
敵数 = round( 乱数 × (3 + 偏り) + 1 + 偏り × 0.5 )   → 1〜5体に丸める
```

**メタルスライム**

| 項目 | 値 |
| --- | --- |
| 出現率 | **1%**（ボス戦を除く） |
| HP | **10** 固定 |
| 物理ダメージ | **1** 固定 |
| 魔法 | **無効** |
| 逃走 | **10秒** |
| EXP | 1戦闘ぶんの **×25** |
| ゴールド | **×3** |

## 6. 現在のバランス（実測）

編成：戦士 / モンク / 白魔道士 / 黒魔道士、オートON。
ヘッドレスsim（`装備を最善手で付け替え・合成・強化し、ガチャは引けるだけ引く`）。
1ステージに30分かかった時点を「壁」としている。

### 6.1 ガチャを引く場合（デバッグ環境の初期課金 💎200 込み）

| ステージ | 1ステージの所要 |
| --- | --- |
| 1 | 48秒 |
| 5 | 12秒 |
| 10 | 17秒 |
| 20 | 67秒 |
| 30 | 169秒 |
| 40 | 339秒 |
| 50 | 609秒 |
| **51** | **36秒** ← 帯2に入り、実績「大陸踏破1」の ×17.5 が乗る |
| 60 | 74秒 |
| 75 | 316秒 |

### 6.2 ガチャを一切引かない場合

| ステージ | 1ステージの所要 |
| --- | --- |
| 1 | 51秒 |
| 5 | 74秒 |
| 10 | 139秒 |
| 20 | 292秒 |
| **29** | **壁**（総プレイ 2.9時間） |

**壁が 29 と 91 に分かれるのが、いまの設計の要点**になっている。

なお 29 という数字は、以前に決めた「ステージ30程度で全滅する」という
目標とほぼ一致している（偶然ではなく、そこが素の戦力の限界だということ）。

## 7. 強化要素を足すときの注意

壁の位置を決めているのは、次の3つの比。

| 決めているもの | 定数 | 場所 |
| --- | --- | --- |
| ⚠⚠ 壁の位置そのもの | 敵の伸び **1.09** | `enemies.js` の `GROWTH` |
| ⚠ 装備で伸ばせる総量 | レア度倍率（UR 5.0625）× レベル上限（+0.05×49） | `inventory.js` の `RARITY` / `LEVEL_STEP` |
| ⚠ 帯をまたいでも進める量 | 実績「大陸踏破」の **×17.5 / 50ステージ** | `data/achievements.js` |

**必ず守ること**

1. 敵の伸びは `実績の乗算^(1/50)` を超えられない。
   いまは `17.5^(1/50) = 1.059` に対して 1.09 なので、意図的に 1.031/ステージぶん
   不足させている。これが「進むほど重くなり、いつか壁になる」の正体。
2. **帯倍率を入れてはいけない**（決定事項）。帯が変わるたびに装備が強くなると、
   装備の伸びが「一度きり」ではなく複利になり、上の計算が崩れる。
3. **敵のDEF・AGIは線形のまま**にする。割合として効くので、指数にすると
   プレイヤーの数値をいくら上げても軽減され続けて詰む。
4. ギルの伸びは敵と同じにしておく。装備の強化費用の基準がギルなので、
   ずらすと「帯の前半は永遠に強化できない」か「初日に全部カンストする」になる。

**強化要素を足したら測り直す**

```sh
node /path/to/sim2.mjs 250        # 壁の位置と各ステージの所要時間が出る
```

味方を硬く／強くする要素を足したときは、敵の伸び（`GROWTH`）を上げて壁を戻す。
0.01 動かすだけで壁が10ステージ以上ずれるので、必ず実測すること。
