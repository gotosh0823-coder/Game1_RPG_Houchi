# バランス定数の一覧

実装に入っている倍率・固定値をすべて並べたもの。**コードが正**で、この文書は写し。
値を変えたら、この表も一緒に更新すること。

`⚠` は、変えると壁の位置が大きく動くもの。

---

## 1. 味方が強くなる要素

プレイヤーの戦力に効く数値。これが「強化」の全体像。

### 1.1 ジョブレベル（EXPで伸びる・上限75）

`js/core/stats.js`

| 項目 | 値 | 備考 |
| --- | --- | --- |
| レベル上限 | **75** | `jobs.js` の `LEVEL_CAP` |
| HP 基礎値 | **150** | Lv1の値 |
| MP 基礎値 | **40** | MPグレードFの戦士・モンクは常に0 |
| ステータス基礎値 | **5** | STR/DEX/VIT/AGI/INT/MND/CHR 共通 |
| HP 1レベルあたり | **6** × グレード係数 | |
| MP 1レベルあたり | **3.5** × グレード係数 | |
| ステータス 1レベルあたり | **0.55** × グレード係数 | |
| 必要EXP | `floor(40 × Lv^1.9)` | Lv1→2で40、Lv74→75で約17万 |

```
HP     = floor( (150 + HP係数 × 6 × (Lv-1))   × 限界突破ボーナス ) + 5 × 突破回数
MP     = floor( (40 + MP係数 × 3.5 × (Lv-1))  × 限界突破ボーナス ) + 5 × 突破回数
その他 = floor( (5 + 係数 × 0.55 × (Lv-1))    × 限界突破ボーナス ) + 1 × 突破回数
```

**グレード係数**（`jobs.js` の `GRADE`）

| A+ | A | B | C | D | E | F |
| --- | --- | --- | --- | --- | --- | --- |
| **2.00** | 1.80 | 1.60 | 1.40 | 1.20 | 1.00 | 0.80 |

> 係数を2倍にしたので、1レベルあたりの伸び（6 / 3.5 / 0.55）と掛け合わせると
> 半減する前の曲線に戻る。Lv50の素のステータスは HP 679（戦士）／
> 主要ステータス 53〜59 程度。

### 1.2 装備（4部位・ステータス加算）

`js/data/equipment.js`。抽象的な装備倍率は廃止し、実際のアイテムに置き換えた。
店が未実装なので、到達ステージ相応のティアを自動で着けている扱い。

| 項目 | 値 | 備考 |
| --- | --- | --- |
| 部位 | 武器 / 鎧 / 脚 / アクセサリ | |
| ティアの間隔 | **2ステージごと** | `STAGES_PER_TIER` |
| **火力側の伸び** | **2.06 / ティア** | ⚠ atk・STR・DEX・AGI・INT。1ステージの所要時間を決める |
| **耐久側の伸び** | **1.90 / ティア** | ⚠⚠ HP・VIT・MND。**壁の位置を決める** |

```
ティア     = floor((最高到達ステージ - 1) / 2) + 1
火力側の値 = 基礎値 × 2.06 ^ (ティア - 1)
耐久側の値 = 基礎値 × 1.90 ^ (ティア - 1)
```

敵は2ステージで ×2.10（HP）／×2.13（ATK）伸びるので、
火力側 2.06 はほぼ釣り合い、耐久側 1.90 だけが遅れていく。

**基礎値（ティア1）**

| 部位 | 種別 | 補正 |
| --- | --- | --- |
| 武器 | 斧（戦士） | atk 9 / STR 4 |
| 武器 | 格闘（モンク） | atk 6 / STR 3 / VIT 2 |
| 武器 | 棍（白） | atk 4 / MND 6 |
| 武器 | 杖（黒） | atk 3 / INT 6 |
| 武器 | 片手剣（赤） | atk 7 / STR 2 / INT 2 / MND 2 |
| 武器 | 短剣（シーフ） | atk 6 / DEX 4 / AGI 2 |
| 鎧 | 重（戦士） | HP 70 / VIT 5 |
| 鎧 | 中（モンク・赤） | HP 50 / VIT 4 / DEX 2 |
| 鎧 | 軽（白・黒・シーフ） | HP 35 / MP 15 / INT 2 / MND 2 |
| 脚 | 重 | HP 40 / VIT 3 |

### 1.3 限界突破

`js/core/save.js`。突破回数を N とする。

| 項目 | 値 |
| --- | --- |
| 条件：ジョブレベル | **75** |
| 条件：ゴールド | `100万 × 2.5^(N-1)` |
| 条件：アイテム | 「偉大な〇〇の証」 **N個** |
| 効果：レベル | **1に戻る** |
| 効果：成長ボーナス | **1 + 0.05 × N**（全ステータスに乗算） |
| 効果：初期ステータス | HP **+5N** / MP **+5N** / その他 **+1N** |
| 効果：獲得EXP | **1 + 0.5 × N** 倍 |

## 3. 戦闘の固定値

`js/core/battle.js`

| 項目 | 値 |
| --- | --- |
| ティック | **0.1秒** |
| MP自然回復（全員共通） | **1.0 / 秒** |
| 白の自動ケアル閾値 | HP **70%** 未満 |
| ケアルのMP消費 | **10** |
| ファイアのMP消費 | **8** |
| TP蓄積（命中1回） | **8%** |
| ウェポンスキル倍率 | **×3.0** |
| 戦闘間の自動回復 | 最大HPの **5%** |
| ヘイトの最低保証 | **5%** |

**計算式**

```
ステータス   = レベルぶん + 装備4部位の合計

攻撃力       = 武器のatk + STR × 0.5
魔力         = INT × 1.8
回復量       = MND × 2.5

物理ダメージ = 攻撃力 × 100 / (100 + 敵DEF) × (0.9〜1.1)
魔法ダメージ = 魔力   × 100 / (100 + 敵MDEF)
被ダメージ   = 敵ATK × 敵ATK / (敵ATK + VIT × 2) × (0.9〜1.1)
命中率       = 75 + (DEX - 相手AGI) × 0.5   （20〜95%）
```

**ヘイト**

```
ヘイト = ( 与ダメージ累計
         + 回復量累計 × 0.5
         + デバフ1回ごとに 敵HP × 0.02
         + 女神の祝福1回ごとに 自分の最大HP × 0.5
         + VIT × 10 )                 ← 戦闘開始時の初期値
       × ジョブのヘイト倍率
```

比率をそのまま狙われる確率にし、5%を下回る者は5%へ引き上げ、
不足ぶんを上回っている者から比例して差し引く。

## 4. 敵の数値（強化の対抗軸）

`js/data/enemies.js`。n = ステージ番号。

| 項目 | 式 | ステージ1 | 10 | 30 |
| --- | --- | --- | --- | --- |
| 1戦闘の総HP | `110 × 1.45^(n-1)` | 110 | 4.1k | 1.8M |
| 敵ATK | `5 × 1.46^(n-1)` | 5 | 190 | 110k |
| 敵DEF | `2 + n × 3` | 5 | 32 | 92 |
| 敵AGI | `2 + n × 1.2` | 3 | 14 | 38 |

- 通常敵1体のHP = 総HP ÷ 敵数（何体出ても総量は一定）
- DEFとAGIは割合として効くので、**指数で伸ばしてはいけない**（線形にしてある）

**ボス（10戦目）**

| 項目 | 値 |
| --- | --- |
| HP | 総HP **×15** |
| ATK | 通常敵の **×1.2** |
| 全体攻撃の間隔 | **20秒ごと** |
| 全体攻撃の倍率 | ATK **×1.5** |
| ゴールド・EXP | **×5** |

**敵の出現数**

```
偏り = min(2, (ステージ-1) / 15)
敵数 = round( 乱数 × (3 + 偏り) + 1 + 偏り × 0.5 )   → 1〜5体に丸める
```

**メタルスライム**

| 項目 | 値 |
| --- | --- |
| 出現率 | **1%**（ボス戦を除く） |
| HP | **10** 固定 |
| 物理ダメージ | **1** 固定 |
| 魔法 | **無効** |
| 逃走 | **10秒** |
| EXP | 1戦闘ぶんの **×25** |
| ゴールド | **×3** |

## 6. 現在のバランス（実測）

編成：戦士 / モンク / 白魔道士 / 黒魔道士、オートON。

| ステージ | 1ステージの所要 | 状況 |
| --- | --- | --- |
| 1〜10 | 44〜99秒 | ティアの切り替わりで上下する（下記） |
| 15 | 81秒 | |
| 20 | 145秒 | |
| 25 | 119秒 | |
| 30 | 187秒 | |
| **31〜34** | 1800〜3000秒 | **壁。数十回全滅しながらレベルを上げて突破する** |
| 35以降 | 214秒 | 突破後は落ち着く |

被弾率：戦士 32% / モンク 23% / 白魔道士 21% / 黒魔道士 23%

**ティアの切り替わりで所要時間が上下する**

装備は2ステージに1回しか強くならないのに、敵は毎ステージ ×1.45 で強くなる。
そのため各ティアの1ステージ目は軽く、2ステージ目は約1.7倍重くなる
（44秒 → 75秒、52秒 → 89秒 …）。

滑らかにしたい場合は `STAGES_PER_TIER` を 1 にして、
伸びを 2.06 → 1.44、1.90 → 1.38 に置き換えれば同じ曲線のまま段差だけ消える。
ただし装備ティアがステージごとに増えるので、店を作るときの品揃えは増える。

## 7. 強化要素を足すときの注意

いま壁の位置を決めているのは **装備の耐久側の伸び（§1.2 の 1.90）** ひとつ。
火力側（2.06）は1ステージの所要時間を決めており、役割が分かれている。

- 味方を**硬く**する強化を足した → 耐久側の伸びを下げて壁を戻す
- 味方の**火力**を上げる強化を足した → 火力側の伸びを下げて所要時間を戻す

どちらも15ティア（30ステージ）ぶん複利で効くので、
**0.03 動かすだけで壁が5ステージ以上ずれる**。強化を追加したら必ず測り直すこと。
