# Game1_RPG_Houchi

ブラウザで動く、ジョブ制の放置RPG。**FINAL FANTASY XI をオマージュ元**とする。

4人パーティが自動で連戦し、プレイヤーは「編成するジョブ」と
「固有アビリティを今使うか、温存するか」だけを判断する。

## 遊ぶ

ビルド不要。ローカルサーバー経由で `index.html` を開く（ESモジュールを使っているため、
`file://` では動かない）。

```sh
python3 -m http.server 8000
# → http://localhost:8000/
```

## 現在の状態（v0）

6画面すべて操作できる。

| 画面 | 内容 |
| --- | --- |
| 戦闘 | 10連戦＋ボス。唯一の操作は固有アビリティ4ボタン |
| 編成 | 4枠にジョブを割り当てる。ジョブ詳細と**限界突破**もここ |
| 装備 | ジョブごとに4部位。ギルでの強化、同名合成、売却 |
| 店 | モグボナンザ（単発 💎5 / 11連 💎50） |
| 実績 | 309段階。自動取得＋通知、進捗バー。**遺物**の収集状況もここ |
| 設定 | 自動売却のレア度、セーブデータの削除 |

### 装備

4部位（武器 / 鎧 / 脚 / アクセサリ）× レア度5段階（N / R / SR / SSR / UR）。
**533種**（ドロップ520 / ガチャ限定13）。

- 拾って持ち、**ギルでレベルを上げ**、**同じ名称**を重ねて1つ上のレア度にする
- レベル上限は N 10 / R 20 / SR 30 / SSR 40 / UR 50。UR 1本に N 54本が要る
- 50ステージごとに「帯」が変わってドロップの名前が変わる（**基礎値は全帯で同じ**）
- 武器はジョブ専用、防具は3グループ（魔道士 / 重量 / 軽量）、アクセサリは全ジョブ共通

装備リストの原本は [data/equipment.csv](data/equipment.csv)（Excelで編集可）。
編集したら再生成する。

```sh
python3 tools/gen_equipment.py
```

### 遺物

**オンライン中に全滅したときだけ**手に入る、永続のコレクション要素。
50ステージごとの帯に10種ずつ、ステージ200まで**40種**。

- 全滅すると、その帯の未入手から3種が提示され、ひとつ選ぶ
- 受け取ると**編成中のジョブレベルが15下がる**（見送ることもできる）
- 効果は帯をまたいで同じ（最大HP +50% / 攻撃力 +50% / 獲得EXP +100% …）
- 1帯10種を集めきると、その帯での全滅では以降なにも起きない

壁で全滅を繰り返す時間に、進行と選択を持ち込むための要素。
1周で15〜18回全滅し、12〜14個ほど集まる。
詳細は [docs/spec-relics.md](docs/spec-relics.md)。

### バランス

**指数（`a^n`）はゲーム内に1つも無い。** 敵もギルもEXPも、
すべて `((n + 15) / 16) ^ 指数` というべき乗にそろえてある。

| 項目 | 式 | ステージ100 |
| --- | --- | --- |
| 1戦闘の総HP | `110 × 倍率(3.0)` | 41k |
| 敵ATK | `5 × 倍率(3.3)` | 3.4k |
| ギル | `8 × 倍率(3.0)` | 3.0k |
| EXP | `9 × 倍率(3.0)` | 3.3k |

プレイヤー側の強化はレベル75・装備UR Lv50・遺物40個と、どれも上限がある。
上限のあるものを指数の相手にすると、いつか必ず詰む。

ヘッドレスsimの到達ステージ（8回）：**93 / 94 / 95 / 96 / 97 / 98 / 103 / 105**。
全滅3〜7回、遺物3〜7個、Lv75はステージ78〜92、所要8〜12時間。
遺物を取らないと 65〜69 で止まる。

装備が「到達ステージから自動で決まる」仕様だった頃は ×1.45 だった。
装備を自力で集めるものにした時点で、プレイヤー側で繰り返し掛かる指数が
実績「大陸踏破」の ×17.5 / 50ステージ（= 1.059/ステージ）だけになったため、
敵のカーブもそこに合わせて下げてある。詳細は [docs/balance.md](docs/balance.md) §4。

## レア枠：メタルスライム

通常戦闘に1%で出現する。魔法は一切通らず、物理も1ダメージ固定。
攻撃してこない代わりに10秒で逃げる。倒せば1戦闘ぶんの25倍のEXPが入り、
EXP全体の約16%を担う。

物理1ダメージ固定なので、効くのは攻撃力ではなく手数だけ。
ただし現行のHP10なら必要な手数は10回で、どの編成でも取り逃がさない
（詳細と、関門として機能させたい場合の数値は仕様書 §8.2 / §14.5）。

## デバッグ用のボタン（画面左上）

| ボタン | 動作 |
| --- | --- |
| `×1` | 押すと **×10**（10倍速）。バランスを見る時に使う。セーブには残らない |
| `💎` | **アレキサンドライトを200個追加**。現在の所持数を表示 |

アレキサンドライトはガチャ通貨（店＝モグボナンザで使う）。
デバッグ環境では初期課金ぶんとして **200個** を持った状態から始まる。

供給は ボス撃破5個 / ログインボーナス100個（1日1回・自動） /
オフライン報酬100個（12時間で上限）＋ 実績報酬。
広告閲覧と課金による入手は後日検討（プロトタイプでは実装しない）。

## 動作確認用

ブラウザのコンソールから叩ける。

```js
game.jump(50)              // ステージ50へ移動
game.state.gold = 1e9      // ゴールドを増やす
game.addAlexandrite(1000)  // ガチャ通貨を増やす
game.limitBreak('war')     // 戦士を限界突破（条件を満たしている場合）
game.METAL.rate = 1        // メタルスライムを毎戦闘出す
```

## 注意

ジョブ名・アビリティ名等の固有名詞は FF11 のものを踏襲しています。
一般公開・配布の際は名称の差し替えが必要になるため、
ジョブとアビリティの定義はデータテーブルに分離する方針です。
