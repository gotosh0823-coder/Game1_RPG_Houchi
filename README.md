# Game1_RPG_Houchi

ブラウザで動く、ジョブ制の放置RPG。**FINAL FANTASY XI をオマージュ元**とする。

4人パーティが自動で連戦し、プレイヤーは「編成するジョブ」と
「固有アビリティを今使うか、温存するか」だけを判断する。

## 遊ぶ

ビルド不要。ローカルサーバー経由で `index.html` を開く（ESモジュールを使っているため、
`file://` では動かない）。

```sh
python3 -m http.server 8000
# → http://localhost:8000/
```

## 現在の状態（v0・仮）

| 画面 | 状態 |
| --- | --- |
| 戦闘 | 実装済み |
| 編成 / 装備 / 店 / 設定 | **仮画面**（切り替わって画面名が出るだけ） |

戦闘まわりは仕様どおり動く。ジョブレベル・EXP・ゴールド・セーブ・
オフライン報酬も動作する。限界突破はロジックのみで、UIは編成画面の実装待ち。

装備は店が未実装のため、「到達ステージ相応の装備を全員が着けている」ものとして
自動的にスケールする暫定実装になっている（詳細は仕様書 §14）。

## 構成

```
index.html
css/style.css
js/
  main.js            エントリポイント・ゲームループ・画面切り替え
  data/jobs.js       ジョブ定義（ステータス補正・固有アビ・パッシブ）
  data/enemies.js    敵の数値テーブル
  core/stats.js      ステータス計算・EXP・装備の暫定スケーリング
  core/battle.js     戦闘シミュレータ
  core/save.js       セーブ／ロード・オフライン報酬・限界突破
  ui/render.js       描画
```

ジョブとアビリティの定義は `js/data/jobs.js` に閉じてある。
固有名詞を差し替える場合はこのファイルだけを書き換えればよい。

## ジョブ

最終的に FF11 の 22ジョブを実装対象とする。v0 では初期6ジョブのみ。

| ジョブ | 固有アビリティ | パッシブ |
| --- | --- | --- |
| 戦士 | マイティストライク | ダブルアタック |
| モンク | 百烈拳 | カウンター |
| 白魔道士 | 女神の祝福 | 女神の羽衣 |
| 黒魔道士 | 魔力の泉 | クリアマインド |
| 赤魔道士 | 連続魔 | 二刀流 |
| シーフ | 絶対回避 | トレジャーハンター |

上級ジョブ16種（ナイト / 暗黒騎士 / 獣使い / 吟遊詩人 / 狩人 / 侍 / 忍者 /
竜騎士 / 召喚士 / 青魔道士 / コルセア / からくり士 / 踊り子 / 学者 /
風水士 / 魔導剣士）は v2 以降。

## 動作確認用

ブラウザのコンソールから叩ける。

```js
game.jump(50)          // ステージ50へ移動
game.state.gold = 1e9  // ゴールドを増やす
game.limitBreak('war') // 戦士を限界突破（条件を満たしている場合）
```

## 注意

ジョブ名・アビリティ名等の固有名詞は FF11 のものを踏襲しています。
一般公開・配布の際は名称の差し替えが必要になるため、
ジョブとアビリティの定義はデータテーブルに分離する方針です。
