# Game1_RPG_Houchi

ブラウザで動く、ジョブ制の放置RPG。**FINAL FANTASY XI をオマージュ元**とする。

4人パーティが自動で連戦し、プレイヤーは「編成するジョブ」と
「アビリティを今使うか、温存するか」だけを判断する。

現在は**仕様検討フェーズ**で、実装コードはまだありません。

## ドキュメント

- [docs/spec-v0.md](docs/spec-v0.md) — 初期仕様のドラフト
  （ジョブ／戦闘／装備／経済／画面構成／実装スコープ）

## ジョブ

最終的に FF11 の 22ジョブを実装対象とする。v0 では初期6ジョブのみ。

| 区分 | ジョブ | 実装 |
| --- | --- | --- |
| 初期ジョブ | 戦士 / モンク / 白魔道士 / 黒魔道士 / 赤魔道士 / シーフ | v0 |
| 上級ジョブ | ナイト / 暗黒騎士 / 獣使い / 吟遊詩人 / 狩人 / 侍 / 忍者 / 竜騎士 / 召喚士 / 青魔道士 / コルセア / からくり士 / 踊り子 / 学者 / 風水士 / 魔導剣士 | v2以降 |

## 注意

ジョブ名・アビリティ名等の固有名詞は FF11 のものを踏襲しています。
一般公開・配布の際は名称の差し替えが必要になるため、
ジョブとアビリティの定義はデータテーブルに分離する方針です。
